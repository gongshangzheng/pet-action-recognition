## 成果

- FastAPI 后端 + Vue 3 前端脚手架跑通，前后端分离架构落地（Vite 3210 → FastAPI 8809）
- 三大模块（管理/论文/评测）路由与页面骨架就位，Naive UI 主题与 MainLayout 侧边栏统一
- 约定 Markdown 数据目录结构，后端只读解析、脚本写入的单源模式确立

## 方法

后端按模块拆 routers + parsers，管理数据全部落 Markdown/JSON 文件；前端 SPA 通过 Vite 代理 /api，按模块组织 views 与 api 封装。

## 问题与解决

macOS 下 nohup 启动的进程收到 SIGHUP 挂起——需 `</dev/null` 重定向 stdin 并 disown。
