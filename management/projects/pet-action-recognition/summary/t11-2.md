## 成果

- 新建 `web/src/api/live.js`：封装 `/api/live/sources`、`/api/live/play_url`、`/api/live/screenshots` 等 API
- 新建 `web/src/views/Live.vue`：三栏布局（源列表 + 视频播放器 + 识别段）
- 新建 `web/src/components/live/VideoPlayer.vue`：视频播放器组件，支持 overlay 叠加

## 方法

- 前端用 Vue 3 `<script setup>` + Naive UI
- 视频播放用 `<video>` 标签，src 指向 `/api/live/stream?token=xxx`
- stream_token 后端签名，前端不暴露 secret
