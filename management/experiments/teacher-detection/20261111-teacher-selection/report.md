## 背景与目标

行为识别流水线把检测模型当**教师**用：它给出每一帧猫在哪（框），下游再按框裁剪训练片段、生成伪标签。教师漏检的帧，下游没有任何补救手段——裁剪会裁到背景，伪标签会缺一格。因此教师的第一指标是**召回**，不是精度。

选教师的过程走过三站。第一站想省事，直接试 COCO 预训练的 YOLO11 能不能用；第二站改用 GroundingDINO，先用小模型 Tiny 把全量语料跑一遍；第三站换更大的 Base 重跑，并与 Tiny 做同帧对比。本文按这三站讲清楚：每站做了什么、拿到什么数、为什么走到下一站。

术语先交代。「锚点」是抽出来做检测的帧，本流水线每 5 帧抽一次（stride=5，15 fps 下约 3 帧/秒），锚点之间的帧靠插值补框。「召回代理」指用人工标注区间的帧当「必然有猫」的分母，算出的段内检出率——它修正了「全帧检出率被空画面稀释」的问题。

## 当前问题

教师选型要回答三件事：现成通用权重能不能直接用；如果能，需要哪一档；GroundingDINO 的两个档位（Tiny 与 Base）该选哪个、值不值多花的算力。

这三件事都只能在教师端量：覆盖多少视频、锚点里有没有框、框准不准。它们不回答下游分类的准确率，本报告也不做这个承诺。

## 实验设计

三站各自的设计如下，共同点是 prompt 与阈值固定、比较时输入同帧。

**第一站：COCO 零样本体检（2026-09-10）。** 在 79 段 cat 语料上跑 yolo11n 与 yolo11s（conf≥0.25、imgsz 1280、GPU 0），逐帧记录 cat / person / bowl 三类的检出与置信度。夜视单独统计，并用两套口径互相校验：口径 A 按小时（19–23、0–6 点），口径 B 按帧内容（亮度 <60 或饱和度 <20，红外帧亮而无色）。为排除「分母里本来就没猫」的干扰，再按 LabelStudio 的标注段做交叉验证：标注段内的帧必然有猫，段内检出率即为召回代理。

**第二站：GroundingDINO-Tiny 全量（2026-11-07 前）。** 统一 prompt `['cat', 'dog']`、box_threshold 0.3、text_threshold 0.3、stride 5，跑全量语料，产出 2,573 段检测缓存。这一站的作用是确立格式与指纹（后续同参数缓存可复用），不是对比。

**第三站：Base 与 Tiny 同帧对比（2026-11-11）。** 同一批全量视频用 GroundingDINO-Base（933 MB）重跑，得到 2,723 份缓存、211,413 个采样锚点；再从夜间低照度、远距离小目标、强反光近景、多目标遮挡、猫爬架多层结构等场景抽 6 个同帧，左 Tiny（红框）、右 Base（蓝框）并排渲染，逐帧核框。

## 结果与分析

**现成权重直接不可用，这是三站里最硬的一条结论。** yolo11n 与 yolo11s 在全量帧上的 cat 检出率只有 32.1% 与 32.3%，两档几乎没差别；换成段内召回代理是 48.5% 与 48.7%，仍不到一半。夜视是塌陷区：口径 B 下两档漏检 89.5% 与 88.9%。按行为标签拆开看，eating 与 drinking 段能到 91%–99%（猫在盆边、身体展开），grooming 只有 10.1%/11.9%、prolonged_stationary 24.1%/27.3%（蜷成一团的形态在 COCO 域外）。这条分布同时给出了标注配比的依据：夜视帧（79 段里 46 段含夜视）与蜷缩形态是必须重点覆盖的两个盲区。

这一站没有回答「YOLO11 架构行不行」，只回答「COCO 权重不能直接用」。两档差距不到 1 个百分点，说明问题不在容量而在域，故后续把它留作蒸馏目标（见主题「学生检测器蒸馏」）。

**Tiny 全量跑通，但暗光与小目标仍漏。** GroundingDINO-Tiny 让整条链路第一次拥有覆盖全语料的检测缓存，可是主推理由只成立到这一步：同帧对比里，夜间暗光帧上 Tiny 输出两个分散的漂移框（0.493/0.419），Base 给出一个紧凑框（0.678）；远距离小目标帧上 Tiny 是 0 框，Base 以 0.378 召回。

**Base 的收益是可量化的覆盖，加上目视的稳定性。** Base 处理了 2,723 个视频（除 14 个文件头损坏、1 个截断），检出质量在 6 个抽样帧上一致更好：暗光、猫爬架暗区、双猫同框（Tiny 0.588/0.402，Base 0.592/0.559）都更稳。反面要说清：多目标遮挡帧上 Base 比 Tiny 多出 1 个候选框（3 对 2），这个多出来的框是否对应真目标没有人工核对，不能算作收益。

**样本量与可比性。** 第一站是 79 段单机位单日素材，结论只代表这个域；两套夜视口径并存是为了让阈值选择不影响结论方向，不是两次独立测量。第三站的同帧对比只有 6 帧，作用是把「Base 更稳」落到可看的证据上，不是召回率的量化估计——两档都没有人工框 GT。

## 结论与下一步

- 现成 COCO 权重在本域不可用（召回代理约 48.5%、夜视漏检约 89%），教师必须域内训练或换成开放词表检测器。
- GroundingDINO-Base 已作为正式教师接入：覆盖 2,723/2,737 段、211,413 个锚点，Tiny 不再保留。
- 已验证的是教师端的覆盖与目视质量；未验证的是召回率的绝对值（缺人工框 GT）与它对下游分类的贡献。
- 下一步缺失的一环是人工框 GT 对照——没有它，任何「教师更准」的说法都只能停在目视层面。
