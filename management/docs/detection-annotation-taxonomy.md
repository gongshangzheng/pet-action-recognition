## 概述

本文档定义 t13-1（YOLO11 宠物场景目标检测）的标注类目与边界规则，是 9 月人工标注的唯一类目依据。类目在任务书原七类（猫、人、食盆、水盆、猫砂盆、玩具、门窗）基础上增加 `cat_face`（支撑中期验收「面部暴露面积占比」上报），另设预标注中间类 `bowl_unspecified`（仅机器预标注使用，人工修正后不得残留）。

**状态：v0.1 草案，待团队评审定稿。评审通过后本文档升 v1.0 并冻结；类目全集以 `preannotation/yolo/classes.txt` 为单一事实源，改动只动一处。**

## 各类标注边界规则

### cat（猫）

- **框到哪里**：整只猫的最小外接矩形，含尾巴尖与耳尖；趴卧蜷缩时按可见轮廓。
- **遮挡**：被家具/人部分遮挡时，按**推测的完整身体**画框（可见 >30% 时必标；<30% 且无法判断位置时不标）。
- **出画截断**：身体部分出画时，框画到画面边缘为止（框贴边是允许的）。
- **多只猫**：每只一框，各自独立标注。

### person（人）

- 完整人形按全身框；只有局部（手伸入喂食、腿走过）时按可见部分框，仍标 `person`。

### food_bowl / water_bowl（食盆/水盆）

- 框整个容器外沿；被猫头伸入遮挡时按容器完整外沿推测补全。
- **空盆也标**（类别由位置/残留物判断；判断不了时标 `bowl_unspecified` 交复核）。
- 食水两用的同一容器：按当前主要内容标一个类，备注字段说明。

### litter_box（猫砂盆）

- 框整个盆体外沿（含边框围栏）；部分入画按可见部分框。

### toy（玩具）

- 框玩具本体；逗猫棒只框玩具端（杆线若清晰可辨则整枝框）。

### door_window（门窗）

- 框门窗洞口（门框/窗框内沿）；多个门窗各自一框。
- 门开/关状态不影响标注；完全被遮挡（如被家具挡死看不见）时不标。

### cat_face（猫脸）——新增类

- **框到哪里**：猫头部**含双耳**的最小外接矩形；侧面/俯仰角度下按可见头部的完整推测轮廓。
- **何时标**：头部可辨认（能看出是这只猫的头）即标；猫完全背对、头部被完全遮挡、或头部小于约 20×20 像素（2880×1620 原图口径）时不标。
- **与其他类的关系**：`cat_face` 框必然落在某个 `cat` 框内；`cat` 不满足可标条件时 `cat_face` 也不标。
- **用途**：中期验收「面部暴露面积占比及时长」= cat_face 框面积 / cat 框面积 的时间序列。

## COCO 预标注类映射

| COCO 类 | 映射目标 | 说明 |
|---------|----------|------|
| `cat` (15) | `cat` | 直接映射 |
| `person` (0) | `person` | 直接映射 |
| `bowl` (45) | `bowl_unspecified` | COCO 无法区分食/水，人工细分 |
| 其余 COCO 类 | 不导出 | 仅上述三类进预标注包 |

## 中期验收特征上报映射

| 验收要求的特征 | 实现来源 | 依赖类目 |
|----------------|----------|----------|
| 画面亮度、对比度 | 全帧像素统计（非检测产物） | 无 |
| 宠物活动幅度 | cat 框中心位移 + 帧差（t13-2 轨迹就绪后） | cat |
| 宠物身体画面中面积占比和时长 | cat 框面积 / 帧面积 的时间序列 | cat |
| 面部暴露面积占比和时长 | cat_face 框面积 / cat 框面积 的时间序列 | **cat_face**（本次新增的动因） |
| 行为识别信息 | 事件引擎（t13-3）+ 动作分类主线（t12） | cat + 区域类 |

## 标注操作约定

- **工具**：LabelStudio，Object Detection with Bounding Boxes 模板，类目名按上表 `类名` 列建立。
- **预标注来源**：zero-shot 体检产出的 predictions（模型：yolo11s，详见产物 README）；标注员对预标注框做修正/补标/删除，`bowl_unspecified` 必须细分。
- **帧集**：`preannotation/labelstudio/tasks.json`（每 2 秒 1 帧，含无检出空帧）。
- **跳过规则**：完全无法判断内容的帧标记 `to_skip`，不硬标。
