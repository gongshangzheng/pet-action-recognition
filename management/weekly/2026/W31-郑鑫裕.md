周报 — 郑鑫裕 — 2026 第 W31 周（07-27 ~ 08-02）

本周我们完成了数据集的整理工作，基于 Animal Kingdom 哺乳动物子集构建的 pet_action_mammal_v0 数据集（2234 段视频，7 类动作标签，训练 / 验证 / 测试为 1801 / 216 / 217 条）已正式接入训练流水线。

随后我们把 registry 中的全部识别模型在该四足数据集上完成了首轮训练与验证。VideoMAEv2-Base 经超参调优后取得 Top-1 84.3%、Top-5 98.1% 的最好结果。统一基线设置下，Swin-Tiny Top-1 74.5%（Top-5 100%）、TimeSformer 73.1%、VideoMAEv2-Base 72.2%、SlowOnly 71.8%、VideoMAE-Base 69.9%、TANet 66.2%、TIN 65.3%、TSM 63.9%、TPN 63.4%、C2D 63.0%、C3D 61.1%、SlowFast 60.6%、TSN / CSN 58.8%、R(2+1)D 57.9%。I3D（33.8%）与 TRN（19.0%）收敛较差；MViT-Small、X3D-XS、UniFormer-Base 三个 run 因配置问题未能完成。

同时，我们在人类动作数据集 UCF101 上对所有模型做了 evaluation（speed run 冒烟测试，每模型 3 段视频）。TSN、TSM、C2D、C3D、I3D、SlowOnly、CSN、R(2+1)D、TIN、TPN、TANet、TimeSformer、MViT-Small、X3D-XS、UniFormer-Base、VideoMAE-Base、VideoMAEv2-Base 等 17 个识别模型 Top-1 全部预测正确（3/3），SlowFast 2/3，TRN 0/3。4 个 AVA 时空检测模型（SlowFast-AVA、SlowOnly-AVA、VideoMAE-AVA、ACRN）因标签空间不同不参与该准确率对比，但推理流程均已跑通。

下周计划基于本轮结果选定主力模型做更细致的 fine-tune 与指标分析（Macro-F1、各类召回率、混淆矩阵）。
