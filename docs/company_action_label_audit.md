## 类别决策

追逐和打闹均有观测，并非零样本；只有 17/15 个视频文件且部分区间很短，
若按同源数据分组留出验证，数据更加有限。不能仅凭计数证明无法训练，
但不适合作为本轮稳定识别与独立验收的主目标。用户已表示这两类过少时
本轮可暂缓；建议保留原标注，只在后续本轮训练类别清单中不纳入，
不改标为活动、不当作无动作或无猫。

主线建议先选 6 类：活动、静止、进食、饮水、抓挠、舔毛。
如厕作为第 7 类候选，需核验剩余可用片段和不同分组的验证覆盖。
啃咬、跌落、抽搐暂缓是新增建议，不在本次只读审计中实施。
稀少类别的素材仍可保留为后续补样、异常案例和小样本探索。

本次有效导出没有独立的呕吐、猫叫/持续叫标签。在后续对话中，
用户确认所有这些标签由其手工标注，本批视频确实没有这三种行为。
因此可以将它们记录为“标注者确认无实际样本”，本轮不设置相应分类输出。
这条结论来自标注者确认，不能由标签零计数单独推出。
跳跃也没有独立标签，但可能包含在活动中，不能认定没有跳跃样本。
本轮缩小闭集范围后，实验报告应明确尚不覆盖项目要求中的全部行为。

## 多猫与重叠仍需处理

每个行为项仅有一个 timelinelabels 标签，但有 242 个视频存在不同标签的
时间区间重叠，合计 68,027 个覆盖帧。这是时间共现统计，不能直接解释为
242 个多猫视频；同猫兼容动作、不同猫和标注误差都可能造成重叠。

有效行为 result 的 type 全部是 timelinelabels，value 字段只包含
ranges 和 timelinelabels，没有在这些行为项中提供猫身份或框/轨迹关联。
结果 id 不能当猫 ID，task 其他元信息不在此次身份审计范围内。
即使去掉追逐、打闹，其他类别仍可能在多猫场景中同时出现；
单猫裁剪训练仍需确认动作属于裁剪目标，不能每条轨迹复制所有场景标签。

对其他类别的样本不平衡应报告每类召回率与宏平均指标，
不能只用总体分类准确率说明所有类别都好。最终可用类别与达标能力
需要视觉复核、分组验证和连续视频测试，本次不作训练效果承诺。
