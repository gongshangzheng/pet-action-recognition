## 已确认的首次运行联网点

只读检查现有 Ultralytics 8.3.0 与 rembg 2.0.59 源码发现：

- `ultralytics/utils/checks.py` 的 AMP 自检实际调用 `YOLO("yolov8n.pt")`。
  因此仅缓存 `yolo11n.pt` 不一定覆盖默认训练的全部下载路径；需缓存自检权重，
  或在离线配置中明确关闭此自检路径（例如暂用 `amp=False`），并记录这一配置。
- 同文件的 `check_font` 可以从 GitHub 获取 `Arial.ttf`；使用绘图/可视化时需要
  预置本地字体或选择经过验证的本地绘图配置。
- `rembg/sessions/u2netp.py` 含 `u2netp.onnx` 的首次获取逻辑；安装 rembg 包不包含该权重。
- Torch/torchvision/timm 的预训练配置也必须指向已经缓存的本地文件。

联网检查与网络下载不是同一件事；禁用包自动安装，也不能保证所有模型资产已齐。
这正是需要一次离线运行检查的原因。

## 建议的关闭条件

1. 固定近期实际使用的模型范围，补齐对应权重、配置、标签和必要附属文件。
2. 在测试进程中禁用自动下载并使用本地路径，做一次各模块及必要串联的最小运行。
   不更改公司防火墙，不读取公司数据；模型执行仍需用户确认测试方案。
3. 检查启动、前向、短程训练/重载和需要使用的 RKNN 路径是否存在遗漏依赖。
4. 保存环境清单、wheel/权重哈希、离线命令和验证报告，再据此申请关闭公网。
