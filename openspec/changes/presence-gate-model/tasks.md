### 附加测试域：老家 79 段（`~/mnt/dxm/dataset_{崔,蒋}`）

33,109 帧 / 36.8 分钟，全部 20260806 单日、不同户不同机位 → 作 **OOD（跨户跨设备）测试集**，不参与训练。

### 两条硬结论

1. **负样本不再阻塞**：164 段未标注视频 + 124 天里的空闲时段提供了无猫候选；仍需人工核验确认（见 1.3b）。
2. **夜视纳入训练**（用户裁定 2026-10-27）→ 原「夜间只评测不训练」作废；随之产生「单模型 vs 双模型」的选型实验（见 3.9）。

## 1. 数据集与标签

- [ ] 1.1 候选池抽样：从 2,737 段按日期分层抽样（每日最多 N 段），生成候选清单；记录抽样种子、日期分布与户分布。
- [ ] 1.2 划分协议：**按日期隔离** train/val/test（124 天，建议 70/15/15 按日期切分，同一日期不跨 split），并**按户分组报告**（跨户泛化单独一列）；老家 79 段作 OOD 测试集。
- [ ] 1.2a 类不平衡处理：在场帧占多数，负样本 SHALL 下采样或加权；策略与正负比写入报告，并在核验集（正负更均衡）上验证没有被扭曲。
- [ ] 1.2b 昼夜域标注：**以画面内容为准**（复盘 `datasets` skill 的既有裁定：文件名时间戳 ≠ 昼/夜，暗房间中午也会切红外）。主判据 = HSV 饱和度均值（`S < 20` ≈ 红外灰度段，与 79 段审计同口径），亮度与时间戳只作辅助元数据、**不得单独作判据**；判据冲突样本单列并人工抽检，阈值与冲突率写入报告。79 段 OOD 集可直接复用 `~/results/batch/saturation_audit.json` + `color_segments.json`。
- [ ] 1.3 **帧级**弱标签：教师 = 采样帧上的 GroundingDINO 检测（每 10 帧一次 → 插值逐帧）与 YOLO11n 交叉校验；冲突帧进核验队列，不静默取其一。
- [ ] 1.3b 负样本构建：164 段未标注视频 + 已标注视频中区间之外的时段 → 候选负样本池；抽样后由人工核验判定 `present/absent/uncertain`（目视拼图），合格者才进训练。**不得**把"未标注"直接当成"无猫"。
- [ ] 1.3c 人工核验集：白天/夜视各 40–60 帧（含低置信帧与出画帧），跨户分布，肉眼判定；与训练/测试段隔离。
- [ ] 1.5 抽帧与落盘：训练帧按 1–2 fps 抽样（受控总量，目标 8–12k 帧），**输出整帧**（长边 1280 JPEG q90）——门控跑在检测之前，输入必须是原始监控整帧，**不得用 followcam 裁剪帧**。

## 2. 模块级延迟拆解（决定 C1 / C2 是否值得）

- [ ] 2.1 在 pet 上对 GroundingDINO-tiny 做一次逐模块计时：Swin backbone / BERT 文本编码器 / Feature Enhancer / Query Selection / Cross-Modality Decoder，输入 800×1333，记录各自 ms 与占比。
- [ ] 2.2 同口径测 256×320 输入下的耗时（门控若可用低分辨率，成本会显著下降）。
- [ ] 2.3 结论：C1（enhancer 之后）与 C2（backbone 之后）分别能省多少，写成表格回填 design D2/D3。
- [ ] 2.4 风险登记：Feature Enhancer 输出经图像↔文本 cross-attention 条件化，走 C1 时文本编码器与增强器均不可省——以 2.1 实测占比验证该判断。

## 3. 候选实现与训练

- [ ] 3.9 **昼夜形态选型实验（用户提出，2026-10-27）**：三种形态同台对比——
  **M1 统一单模型**（白天+夜视混训，域标签不进模型）/ **M2 双模型**（各训一个 + 域路由：`sat/luma` 判据选模型）/ **M3 单模型 + 域条件**（域 embedding / 双 BN / 域归一化）。
  评测必须**按域分表**（day 召回/误检、night 召回/误检、总体），并记录维护成本（权重体积、路由阈值敏感性、部署复杂度）。
  判据：若 M1 与 M2 的按域指标差 ≤1 个百分点，选 M1（单套权重、少一条路由）；否则按域拆。
- [ ] 3.9a 域路由预研：仅当 M2/M3 胜出时做——路由判据（饱和度/亮度阈值）在核验集上的误路由率，以及误路由时的性能损失。
- [ ] 3.1 `petlib/gate/`：判定器抽象（**`fit(frames, labels)` / `predict(frame) -> p_cat`** / 后处理 `to_timeline(probs, ts)`）+ 契约测试（同一接口四个实现可互换；**同一帧在不同调用位置必须给出同一概率 → 无帧间状态**）。
- [ ] 3.2 候选 A：YOLO11n 单类「猫」（256–320px，**单帧输入**），用弱标签 + 核验集微调/训练；记录 mAP50 与帧率。
- [ ] 3.3 候选 B：MobileNetV3-Small 二分类（224–256px，**单帧输入**），弱标签训练。
- [ ] 3.4 候选 C1：冻结 GDINO，取 Feature Enhancer 后**单帧**多尺度特征 → 薄头（1×1 降维 64 + GAP + 2 层 MLP，参数量 < 10 万）→ 训练；
- [ ] 3.5 候选 C2：冻结 GDINO backbone，取增强器之前**单帧** Swin 多尺度输出 → 同款薄头 → 训练。
- [ ] 3.6 候选 D：帧差 / MOG2 运动能量基线（帧对信号、零训练），作为「只靠运动不行」的对照证据——它**不是**同类实现，只在报告里作参照。
- [ ] 3.7 特征缓存实验（**调度层优化，不改模型**）：固定 `f`（如每 5 帧）跑重模块，中间帧用低成本信号（帧差）决定是否重跑，统计省下的时间与漏检代价。
- [ ] 3.8 后处理层：区间合并、迟滞（连续 N 帧才切换）、最短持续时长、与视频时间戳对齐；单测覆盖抖动序列、单帧闪断、段尾截断。该层参数改动 MUST NOT 触发模型重训。

## 4. 评测（召回优先）

- [ ] 4.1 **帧级**主指标（衡量模型，**按域分表**）：白天与夜视各自的逐帧漏检率（目标 ≤ 2%）、误检率、AUC；阈值扫描给 ROC 与选点依据。OOD（老家 79 段）单列。
