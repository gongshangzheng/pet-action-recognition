## 1. 数据集与标签

- [ ] 1.1 **帧级**弱标签构建：由 `track.json` 的猫框存在性（每 10 帧检测 → 线性插值到逐帧）生成**逐帧**「有猫/无猫」标签（模型输入是单帧，标签也是单帧），落 `results/gate/labels/`，记录教师来源与插值规则。
- [ ] 1.2 划分协议：**按家庭留一（leave-one-household-out）**——训练/验证/测试在家庭维度隔离（崔 22 段 / 蒋 57 段的**白天段**），两侧各跑一遍报平均；段级隔离（同段帧不跨 split）。原「按日程日隔离」作废——79 段同属 20260806 一天。
- [ ] 1.2a 类不平衡处理：在场帧占绝大多数（在场率约 0.94），负样本 SHALL 下采样或加权，避免模型倾向「恒判有猫」；下采样策略与正负比写入报告，并在核验集（正负更均衡）上验证没有被下采样扭曲。
- [ ] 1.3 人工核验集：两家庭各 30–50 帧（共 60–100 帧），肉眼判 `present` / `absent` / `uncertain`，落 `results/gate/manual_check/`；与训练/测试段隔离，并含低置信帧（cat_conf < 0.5）。
- [ ] 1.3b **负样本获取（阻塞项，需用户决策）**：现有白天语料无无猫帧。三条候选：① 用户补录白天「猫不在房间」1–3 分钟片段（两户各一段最佳，最干净）；② 若存在「猫走出画面」的历史片段，从出画后时段挖；③ 降级方案：只训练「有猫概率」，低置信输出 `unknown`，不声称能判无猫。选定前不进入 3.x 训练。
- [ ] 1.4 夜视集：从其余 45 段（小时 0–5 / 20–23）按夜视判据抽 6–10 段，只做 `unknown` 域与召回评测，不进训练。
- [ ] 1.5 抽帧与落盘：训练集每 0.5 s 一帧（≈ 白天 1,600 帧上下），**输出整帧**（长边 1280 JPEG q90）——门控跑在检测之前，输入必须是原始监控整帧，**不得用 followcam 裁剪帧**。

## 2. 模块级延迟拆解（决定 C1 / C2 是否值得）

- [ ] 2.1 在 pet 上对 GroundingDINO-tiny 做一次逐模块计时：Swin backbone / BERT 文本编码器 / Feature Enhancer / Query Selection / Cross-Modality Decoder，输入 800×1333，记录各自 ms 与占比。
- [ ] 2.2 同口径测 256×320 输入下的耗时（门控若可用低分辨率，成本会显著下降）。
- [ ] 2.3 结论：C1（enhancer 之后）与 C2（backbone 之后）分别能省多少，写成表格回填 design D2/D3。
- [ ] 2.4 风险登记：Feature Enhancer 输出经图像↔文本 cross-attention 条件化，走 C1 时文本编码器与增强器均不可省——以 2.1 实测占比验证该判断。

## 3. 候选实现与训练

- [ ] 3.1 `petlib/gate/`：判定器抽象（**`fit(frames, labels)` / `predict(frame) -> p_cat`** / 后处理 `to_timeline(probs, ts)`）+ 契约测试（同一接口四个实现可互换；**同一帧在不同调用位置必须给出同一概率 → 无帧间状态**）。
- [ ] 3.2 候选 A：YOLO11n 单类「猫」（256–320px，**单帧输入**），用弱标签 + 核验集微调/训练；记录 mAP50 与帧率。
- [ ] 3.3 候选 B：MobileNetV3-Small 二分类（224–256px，**单帧输入**），弱标签训练。
- [ ] 3.4 候选 C1：冻结 GDINO，取 Feature Enhancer 后**单帧**多尺度特征 → 薄头（1×1 降维 64 + GAP + 2 层 MLP，参数量 < 10 万）→ 训练；
- [ ] 3.5 候选 C2：冻结 GDINO backbone，取增强器之前**单帧** Swin 多尺度输出 → 同款薄头 → 训练。
- [ ] 3.6 候选 D：帧差 / MOG2 运动能量基线（帧对信号、零训练），作为「只靠运动不行」的对照证据——它**不是**同类实现，只在报告里作参照。
- [ ] 3.7 特征缓存实验（**调度层优化，不改模型**）：固定 `f`（如每 5 帧）跑重模块，中间帧用低成本信号（帧差）决定是否重跑，统计省下的时间与漏检代价。
- [ ] 3.8 后处理层：区间合并、迟滞（连续 N 帧才切换）、最短持续时长、与视频时间戳对齐；单测覆盖抖动序列、单帧闪断、段尾截断。该层参数改动 MUST NOT 触发模型重训。

## 4. 评测（召回优先）

- [ ] 4.1 **帧级**主指标（衡量模型）：核验集逐帧漏检率（目标 ≤ 2%）、同表给误检率、AUC；按阈值扫描给出 ROC 与选点依据。
- [ ] 4.1b **区间级**指标（衡量后处理）：在场区间的边界滞后（秒）、区间数、碎片化程度、误切次数；与帧级指标分表报告，不互相替代。
- [ ] 4.2 教师标签上的指标（蒸馏一致性）单独报告，明确标注「不得作为可靠性结论」。
- [ ] 4.3 门控频率敏感性（**调度参数扫描，模型不变**）：`f ∈ {1,2,5,10,15} Hz` 下漏检率 / 边界滞后（秒）/ 早退节省比三条曲线。
- [ ] 4.3b 后处理参数敏感性：迟滞帧数 × 最短持续时长网格，给出区间级指标变化（用于定参，不再重训）。
- [ ] 4.4 夜视召回：红外段上的召回率与 `unknown` 比例；不达标时记录是否需要 `unknown` 保守放行。
- [ ] 4.5 硬件估算：pet 4090 单帧延迟与显存；RV1126B（INT8）可行性与帧率区间估算。
- [ ] 4.6 选型报告 `results/gate/gate_selection_report.md`：候选矩阵 + 逐项数字 + 推荐（含「服务器实现」与「边缘实现」两个推荐）。
