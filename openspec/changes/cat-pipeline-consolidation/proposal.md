## Why

原始视频、教师检测、目标跟踪和动作训练的资料分散，且 YOLO 教师伪标签路线与动作路线需要共同的数据隔离边界。现有清单只覆盖带标注视频，不能代表全部视频。

## What Changes

- 规划从全部源视频建立清单，与人工动作标注关联；教师检测和去重作为两路共享前置，跟踪供动作路线使用。
- 规划离线 GroundingDINO-base 小批核对，再按用户决定开展教师检测；保留原始候选及独立的处理结果。
- 从共享结果分别构建 YOLO 伪标签数据集和离线裁剪的动作数据集，两路遵守相同的源视频隔离边界。
- 明确在线学生检测、跟踪、裁剪和动作分类的边界，以及版本化数据、统计和可追溯性。
- 后续整理通用处理能力与正式入口到 `petlib`，补充数据卡与项目导航；具体任务结构待用户确认。

## Capabilities

当前 change 使用 `skip_specs: true`，这是本轮设计落盘的现状而非最终规格判断。扩展范围涉及行为变化；完成主目录交接后，须核对现有主 spec、确定是否需要 delta spec 及其归属，不能把当前校验通过当作规格已完备。

## Impact

后续可能影响 `petlib`、检测与数据准备入口、训练数据、项目说明及远程数据布局；本轮只修改本 change 的规划文件，不运行处理或训练。`gdino-base-upgrade` 与 `gdino-distill-yolo-detector` 尚未整合或归档；相关证据及已完成工作必须保留。主目录不干净，合并和交接暂停，现有 tasks 与新设计有冲突，未获结构确认前不得据旧任务实施。
