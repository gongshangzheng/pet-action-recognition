- [ ] 1.1 `petlib/background/`：常驻清单数据结构（`object_id/mask_rle/bbox/embedding/first_seen/last_moved/semantic_label`）+ per-camera JSON/NPZ 读写，路径 gitignore。
- [ ] 1.2 契约测试：清单写入/读取往返一致、并发写入加锁、旧版本文件缺字段时的兼容读取。

## 2. 关键帧分割（首次建库）

- [ ] 2.1 关键帧 SAM 分割 CLI：自动网格 prompt + 已有检测框 prompt 两种模式；产物落 per-camera 清单。
- [ ] 2.2 过分割过滤（D7-3）：面积 / 稳定性 / 出现时长过滤，参数可配并有默认值。
- [ ] 2.3 与 GDINO 家具框合并去重（D7-4）：IoU 超阈值判同一物体，低重叠情况记录待定。
- [ ] 2.4 二次分类槽位（D7-2）：先落 CLIP 零样本候选，接口可替换；无权重时降级为「未知物体 #N」。

## 3. 变更触发与局部重分割

- [ ] 3.1 MOG2 前景 + 猫框剔除（膨胀边缘），记录剔除前后前景面积比。
- [ ] 3.2 持续性迟滞（初值 10 s）：瞬态变动不触发；迟滞时长可配并写入产物元数据。
- [ ] 3.3 局部重分割：变动 bbox 外扩 20% 裁剪 → SAM → 与清单求交 → 挪动/新物体二分。
- [ ] 3.4 状态机（稳定/变更/更新三态）落地 + 全图重建两种触发（首次、累计修正过多 / 机位移动）。
- [ ] 3.5 边界用例：从猫框边缘生长出来的变动（猫叼走物体）不立即触发；曝光缓变不触发。
