# Proposal: 补齐 cat 数据集源侧复查与旧路径 provenance

## Why

`recover-owned-cat-dataset`（已归档）完成了本地归档副本的恢复与逐文件核验，但两项证据因**外部条件缺失**未能取得：
① 云电脑/源侧文件、目录、权限与实际数量的只读复查未执行；② 旧路径版标注/映射报告未取回。
这两项不产生新的本地数据，也不能在无连接条件下造假；把它们继续挂在已完成的恢复 change 上会让"完成"与"证据齐全"混在一起。

## What Changes

- 单独承接两项**外部条件依赖**的取证任务：源侧只读复查、旧路径 provenance 附件恢复。
- 明确取得条件（可用连接 / 云电脑会话）与缺失时的记录方式：缺失即记录为缺失项，不替代、不推断。
- 不改动 `datasets/cat_raw/` 已有归档副本，不重跑恢复流程。

## 边界

- 本 change 只产出**证据与缺失清单**，不改数据、不训练、不改标注语义。
- 旧路径标注取回后仅作 provenance 保存，不得声明为新机器可直接使用的训练清单。
