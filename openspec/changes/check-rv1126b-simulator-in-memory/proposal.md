# RV1126B 模拟器最小可行性检查

用户要求「简单测一下可行性吧，也不要保存结果」。在既有公司环境执行一个极小 CNN 的 ONNX 加载、RV1126B 构建、PC 模拟推理与数值对照，补充先前仅导入检查的覆盖。

不读取真实数据，不下载/安装，不训练、不导出 RKNN 文件、不调用板端性能接口。输入、输出、模型均只留内存；SDK 必需的临时文件使用服务器 tmpfs，结束清除。代码和 OpenSpec 按项目纪律先提交，再同步执行。

验收：每个 API 返回成功，输出形状和数值正确，与 PyTorch/ORT 差异符合所用精度容差；终端逐项显示结果和失败阶段。不以一个小网络通过推导全部候选模型均能部署，也不报告板端帧率。
