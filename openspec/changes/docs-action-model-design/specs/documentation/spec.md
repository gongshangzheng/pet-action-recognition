## ADDED Requirements

### Requirement: 章节结构以本 Change design 为唯一依据

《动作识别模型设计》的章节清单、每章职责与细章分解 SHALL 以本 Change design 的「章节清单」为唯一依据；结构级变更 MUST 先修订 design 并经用户审核，之后才能改正文。

#### Scenario: 请求把跨模型内容写进 《动作识别模型设计》

- **WHEN** 有人想把实时性 / 流式、门控、跨模型协作等跨环节内容写进 《动作识别模型设计》
- **THEN** 按 `docs-system` 的职责裁定移交 《系统架构》《系统架构》，《动作识别模型设计》只保留单模型内部设计

#### Scenario: 请求改 《动作识别模型设计》章节结构

- **WHEN** 有人要求调整 《动作识别模型设计》的章节顺序或拆分方式
- **THEN** 先修订本 Change design 的目标结构与读者动线，经用户审核后再动正文

### Requirement: 引用闭合

《动作识别模型设计》文档内与指向 《动作识别模型设计》的节引用 SHALL 全部可解析（引用 → 标题闭合，悬空 = 0）；章节编号重排 MUST 级联全仓引用（《系统架构》 / papers 笔记 / 各 change design）并核对。

#### Scenario: 章节重编号后

- **WHEN** 《动作识别模型设计》章节编号发生变化
- **THEN** 全仓「《动作识别模型设计》 §X.Y」引用级联重映射，并以闭合核对（悬空 = 0）作为任务完成标准
