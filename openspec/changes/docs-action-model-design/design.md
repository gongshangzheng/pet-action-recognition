# Design: docs-action-model-design

> 本 design 是《动作识别模型设计》**结构**的唯一依据（与 `docs-architecture` design 之于《系统架构》同理）。
> 结构级变更：**本文件先经用户审核，之后才能动正文**。

## 目标结构

```
§1  框架总图
    §1.1 完整结构图（身份编码两方案 + 动作编码两方案 + 解码 + 下游）
          + 图怎么读（模块 → 章节对照小表）
    §1.2 设计目标与非目标（范围界定：可分解 / 可重建 / 可解释 / 数据效率；不做的三件）
          ——能力目标（做到哪一级）指向《系统架构》§2 待审项，本文档不重述
§2  当前待决策
    （模型级 🔴 2 + 🟡 8 表）
§3  身份编码
    §3.1 方案一：模型内 register / TIV（全局注意力注意每一帧 → 聚合 → 身份）
         —— 含该方案开口项：身份是给定还是推断 / 压缩与数量 / 与动作 token 的隔离
    §3.2 方案二：外挂预训练编码器（DINOv2 / DINOv3 / OmniMate 式 VAE）
         —— 含该方案开口项：冻结还是微调 / 如何进解码器
    §3.3 两方案对照（身份给定 vs 推断 / 参数与成本 / 解耦保证来源 / 专属风险）
         含共有问题：参考输入形态 / 多图与视频聚合 / 是否需要独立身份损失
         含组合约束：TIV 不能配卷积式
§4  动作编码
    §4.1 方案一：TV token（3D patchify + 每 tubelet 局部注意力）
    §4.2 方案二：卷积式（2D CNN 逐帧 + 时序模块｜或 3D CNN 聚合 t 帧）
    §4.3 两方案对照
         含共用：正交约束作用对象（token 式→可作用于 token；卷积式→只能作用于投影系数）
                / 聚合粒度（每 t 帧一份）/ 变长输入输出 / 编码器选型与初始化
         含组合约束：卷积式只能配外挂身份
§5  解码与重建
    §5.1 解码器（身份 + 正交基系数 → 重建帧）
    §5.2 不用 warp / `feats`
    §5.3 连续潜空间（为什么不做离散化）
    §5.4 损失设计
§6  训练流程与对比实验
    §6.1 两阶段（A 人类数据 → B 猫语料）
    §6.2 训练细节（自重建 / 用法 / 分工）
    §6.3 理论对比：解耦 vs 直接监督
    §6.4 对比实验设计（可行三组组合）
§7  评测矩阵
§8  下游：行为素序列 → 动作识别
    §8.1 行为素序列 → 分段（只定边界）
    §8.2 分段 → 类别（聚类+命名 / 有监督 / 混合）
    §8.3 与 `video-action-segmentation` / `video-feature-latent` 的分工
§9  谱系与合规
    §9.1 谱系：借什么、否什么
    §9.2 许可与合规
§10 参考来源
附录 符号速查
```

**为什么身份与动作各占一章、章内再分两方案**：身份侧分叉在「身份从哪来」，动作侧分叉在「时序怎么建模」——两处都是二选一，且各有自己的对照维度。把「两方案 + 对照」放同一章，共有问题（参考形态、聚合粒度、正交约束作用对象）直接落在该章对照里，不另设章。

**为什么「设计目标与非目标」不进 §2 待决策**：§2 装的是**还没定的开放问题**（参考聚合方式 / 动作风格归属 / 基座选型等）；目标与非目标是**已定的范围界定**（做什么、不做什么），性质不同。唯一的例外是「动作识别能力要做到哪一级」——那是**待审定**的，但它在《系统架构》§2 的「目标与形态级」，本文档引用即可。

**为什么下游单独成章**：编码器只产出**行为素序列**，重建只是 proxy；真正交付的是「动作段 + 类别」。这段由 §8 承接（实现落在 `video-action-segmentation` / `video-feature-latent`）。

## 读者动线

```
总图（整体 + 两处分叉）
  → 待决策（哪里还没定）
    → 身份编码（两方案 + 对照）
      → 动作编码（两方案 + 对照）
        → 解码与重建（两条通路汇合）
          → 训练与对比实验
            → 评测矩阵
              → 下游：行为素序列 → 动作识别
                → 谱系与合规 / 参考来源
```

- **身份编码在前**：它是最宏观的分叉（一个模型 vs 两个模型）
- **动作编码随后**：分叉在时序建模方式，与身份方案可正交组合
- **解码重建第三**：身份与动作在此汇合，重建只是 proxy
- **下游最后**：行为素序列的消费方
