# 抽样设计

从路径版 CSV 收集不同视频路径与其动作类别，固定随机种子 20261010，
优先每个已出现类别抽一个不同视频，共至多 12 个，若仍不足再随机补齐。
这是按标签分层的抽样，不保证不同视频文件是不同家庭或独立事件。

使用公司现有 `.runtime/pet` 的 PyAV 12.3.0，以只读方式 av.open，
查看 container.streams 中 video/audio 的数量、codec、尺寸、average_rate、
duration；不调用 decode 或 demux，不建立输出文件。
系统 PATH 没有 ffprobe，但已经安装 PyAV 和 imageio-ffmpeg，无需安装依赖。

CSV 读取前后 SHA256 保持不变，抽样视频 size/mtime/inode 在读取前后检查。
仅输出路径哈希作为样本编号、所选类别和媒体属性，不输出文件名或原标注内容。
脚本提交后以校验 SHA256 的 base64 送入远程 Python 内存。

有音频流不等于有猫叫，没有音频流也不能据此判断画面中是否张嘴叫。
用户作为标注者已确认本批素材没有呕吐、猫叫和持续叫行为；
该确认与此次容器音轨检查分别作为证据保存，不靠统计缺标签推断。
