## ADDED Requirements

### Requirement: 行为素序列的动作分割（行为素 → 动作段）

系统 SHALL 提供「行为素序列 → 动作段」的分割能力：给定行为素 / `λ` 序列，输出**动作段列表**（每段含起止时间 + 类型），供应用出口直接渲染为报告。分割 MUST NOT 依赖动作标签或段边界标注。

系统 MUST 采用「**先粗后细**」的流程：先用 `λ` 运动能量得到**强边界候选**并把长视频切成若干「行为块」，再在块内做细分段与段类型聚类。

段类型 MUST 经人工命名后才作为最终标签；命名前以内部 ID 呈现。

#### Scenario: 从 λ 序列产出段列表

- **WHEN** 输入一段含多个行为的长视频的 `λ` 序列
- **THEN** 输出动作段列表（起止秒 + 类型 + 置信度 + 段内行为素数），段序与时间轴一致、无重叠、无缺口

#### Scenario: 静止段的双重语义区分

- **WHEN** 某连续区间内运动能量低于阈值（视觉上静止）
- **THEN** 系统 MUST 按**时长阈值**分流：短于 `T_pause` → 视为**边界/分隔符**（不单独成段）；不短于 `T_pause` → 视为**静止型行为段**并参与类型聚类

#### Scenario: 边界候选不单独决定分段

- **WHEN** 运动能量边界与细分段模型给出的边界不一致
- **THEN** 系统 MUST NOT 仅凭能量边界定段；须以细分段结果为准，并记录两者不一致处供人工复核

#### Scenario: 跨块同一行为的合并

- **WHEN** 同一行为被能量边界切成相邻两块、且两块的段类型相同、时间间隔小于阈值
- **THEN** 系统 MUST 合并为一个动作段（不产生人为断裂）

#### Scenario: 无监督 TAS 的输入不预先离散化

- **WHEN** 执行细分段与类型聚类
- **THEN** 输入 MUST 为**连续** `λ` 序列或连续段表征，MUST NOT 先经 VQ / 硬聚类量化（避免序列过长导致分词失效）
