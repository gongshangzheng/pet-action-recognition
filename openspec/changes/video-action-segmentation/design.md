# Design: video-action-segmentation

> 总管：`pet-motion-latent-pipeline` **2.4b**（插在 2.4 `video-feature-latent` 与 2.5 `spot-check-cli` 之间）。
> 领域背景与既有模型的做法见 [`papers/docs/action-recognition-models.md`](../../../papers/docs/action-recognition-models.md)；概念与音频类比见 [6 号《系统架构》§1.8](../../../management/docs/architecture.md)。

## Context

- **已有**：`λ` 序列设计（`identity-action-tokenizer`）；行为素/聚类设计（`video-feature-latent`）
- **缺口**：**行为素（词）→ 动作段（句）** 的组合层——目前只以 `video-feature-latent` 的「阶段三（条件启动）」形式存在
- **出口约束**：`spot-check-cli` 的报告形态是**段列表**（标签 + 起止秒），必须由本层提供
- **主流模型的现状**（须讲清，避免误解）：主流动作识别（A1 层）**输入固定 T 帧、输出 1 个标签**，**这不是错**——它是"已裁剪片段分类"这个任务的正确解；我们问题是**任务不同**（未裁剪长视频 → 多段 + 时间戳）

## Goals / Non-Goals

**Goals:**

- 把行为素序列切成**动作段**，并给每段一个（可命名的）类型
- **无需动作/边界标注**（本项目不具备逐帧标注）
- **静止段**语义可判：区分「停顿（分隔符）」与「静止型行为（睡觉）」
- 产出可直接驱动 `spot-check-cli` 的报告

**Non-Goals:**

- 不做有监督 TAS（需逐帧标注，不具备）
- 不做 TAD（需边界标注，不具备）
- 不重新训练编码器（消费 `λ` / 行为素即可）
- 不做实时（实时是 `spot-check-cli` 的出口形态；本层先产出离线段列表）

## Decisions

### D1: 本层是**主线的必要一层**，不是"条件启动的升级"

**决策**：`行为素 → 动作段` 的分词层 MUST 进入主线，不得仅作为"阶段二闸门失败后的补救"。

**理由**：句子必然要分词。若阶段二（纯聚类）闸门通过就停下，则只得到**行为素词表**，无法输出「猫在舔毛」这种**组合型动作**。

**连带**：`video-feature-latent` 的阶段划分需同步调整（其"序列层"从条件启动提为主线）。

### D2: 三步组合（能量预分段 → 无监督 TAS → 人工命名）

```
① λ 运动能量预分段（零成本）
     energy(j) = Σ_m |λ_m(j)|
     低能量段 → 强边界候选  → 长视频降维成若干「行为块」
② 无监督 TAS 细分段 + 类型聚类（每块内）
     候选：TAEC（2303.05166）/ Temporally-Weighted Hierarchical Clustering（2103.11264）
     输出：块内边界 + 段类型（未命名）
③ 人工命名段类型（看每段代表帧）
```

**为什么先做 ①**：
- **零成本**——`λ` 本身就是运动系数，`Σ_m|λ_m|` 直接是能量曲线
- **降维**——把长视频切成短块，让 ② 在**更短、更同质**的片段上工作
- **有音频先例**——pause-based segmentation / VAD 是 ASR 的常用前置
- **⚠️ 但要正视其局限**（音频论文已指出，arXiv 2203.15479）：*"pauses **do not necessarily coincide with semantic boundaries**. **Over-segmentation**"* → 所以 ① **只作强边界候选**，不单独决定最终分段

**为什么 ② 用无监督 TAS**：其输入输出与本项目完全一致（长视频 → 段边界 + 学到的类别，无需标注），且已成熟 ⇒ **优于自研「中值滤波 + Viterbi 后处理」**。

### D3: 「静止段」的双重语义与时长阈值

**问题**：同一信号（静止）有两种语义——

```
蹲 3 秒    → 动作之间的停顿（分隔符）
蹲 20 分钟 → 睡觉（一种行为！）
```

**决策**：静止段 MUST 按**时长阈值**分流：
- `静止时长 < T_pause` → 视为**边界/分隔符**（不单独成段）
- `静止时长 ≥ T_pause` → 视为**静止型行为段**（需进 ② 参与类型聚类）

`T_pause` 初值待定（候选 3–10 s），由任务 1.3 实测确定。

### D4: **不先把 `λ` 离散化**

**决策**：分词层的输入是**连续 `λ` 序列**，MUST NOT 先做 VQ / 硬聚类。

**理由**（音频实证，arXiv 2106.04298）：*"neural models for speech discretization are **difficult to exploit**... it might be necessary to **adapt them to limit sequence length**"*；最佳分词结果来自**高压缩的表示**。

**推论**：行为素序列不宜过长——`λ` 粒度是 t=4 帧（`30 min @15fps ≈ 27000 帧 ≈ 6750 个 λ`），若再离散化会更长。因此**在连续空间做变化点检测/DP 分词**优于"先离散再分词"。

### D5: 实现路径（含音视频两条范式）

| 路径 | 做法 | 优先 |
|---|---|---|
| **A. 视/听觉无监督 TAS** | 移植 TAEC / TW-Hierarchical Clustering | **首选**（成熟）|
| **B. 层次 HMM + 时长先验** | 时长先验作转移概率（音频 1806.01665 范式）| 备选 |
| **C. DP/Viterbi 最优分词** | NLP unigram 范式：`max Σ log P(段) + log P(长度)` | 备选（轻量）|
| **D. 联合分割 + 词表发现** | 任意长度段 → 固定维嵌入，同时学边界与类型；不预设词表大小（音频 1603.02845 范式）| **最贴本需求，但实现最重** |

## 输入契约

| 输入 | 来源 | 形态 |
|---|---|---|
| `λ` 序列 | `identity-action-tokenizer` | `[J, M]`，每 t=4 帧一个 |
| 段/窗口表征 | `video-feature-latent` | `[J, d]`（用于类型聚类）|
| （可选）行为素簇 ID 序列 | `video-feature-latent` | `[J]` |

## 输出契约

```
[{start_sec, end_sec, action_type, confidence, n_primitives}]
```

- `start_sec` / `end_sec`：秒级（@15fps，帧号 ÷ 15）
- `action_type`：**人工命名**后的类型（未命名时给内部 ID）
- 直接供 `spot-check-cli` 渲染报告

## Risks / Trade-offs

| 风险 | 缓解 |
|---|---|
| **静止 ≠ 语义边界**（音频已知局限）| ① 只作**强边界候选**，不单独定段；② 与 ② 的结果交叉校验 |
| **过分割**（音频已知局限）| 最小段长约束（等价于时长先验）+ 后处理合并 |
| **不是所有切换都有停顿**（走→跑连续）| 不能只靠能量；需 ② 的模型在块**内**继续切分 |
| **行为素序列过长**（6750 个 λ / 30 min）| 不先离散化（D4）；能量预分段降维 |
| 外部 TAS 代码许可不明 | 优先 MIT/Apache；无许可则只借鉴算法自写 |
| 无监督段类型不稳定（同一行为被拆/被并）| 多组超参跑，人工看代表帧裁决；与人工标注 NMI 作辅助 |

## Open Questions

- `T_pause`（静止→停顿 vs 行为的时长阈值）取多少？
- 块间的**跨块一致性**：同一行为被能量边界切成两块，如何合并？（候选：相邻块段类型相同且间隔 < 阈值 → 合并）
- 段类型的**层级**：是否需要"音节层"（介于行为素与动作之间）？
- 无监督 TAS 的输出类型数如何定？是否与 `video-feature-latent` 的行为簇数对齐？
- 是否需要保留少量人工标注做**验收基线**（C33 的"片段级标注"路线）？
