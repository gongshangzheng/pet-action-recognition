## ADDED Requirements

### Requirement: 登记-检索身份架构

系统 SHALL 提供统一的登记-检索机制：用户提交登记照（猫或物品，各 3–5 张）→ 视觉编码器 embedding → 特征库；画面中候选区域 MUST 支持实例级判定（与登记照余弦最近邻 + 阈值）。静态物体候选生成 SHALL 支持固定机位优化（一次分割缓存 + 变更触发重分割），不依赖文本检测词表。

#### Scenario: 登记照检索识别猫

- **WHEN** 已登记 2 只猫各 3–5 张照片，抽查画面中框出一只猫
- **THEN** 系统返回最相似登记身份及相似度；低于阈值时输出「未知猫 #N」

#### Scenario: 文本检测失效物体的实例识别

- **WHEN** 某物体（如喂食碗）文本检测不可靠但已登记照片
- **THEN** 系统通过分割候选区域 + embedding 检索判定其身份与位置，无需文本 prompt

#### Scenario: 固定机位静态物体缓存

- **WHEN** 摄像头位置未变且已完成一次全图分割
- **THEN** 静态物体 mask 缓存复用；检测到画面变更（帧差）时局部重分割
