## ADDED Requirements

### Requirement: 窄屏文档选择器独占一行且正文整宽
视口 <1024px 时，文档页 SHALL 采用纵向布局：文档选择器独占一行、宽度为容器整宽，正文在其下方占满容器宽度；
MUST NOT 让选择器以横向子项的形式与正文分享同一行。视口 ≥1024px 时 SHALL 恢复「左栏 + 正文 + 右栏」横向三栏布局。
窄屏下页面与正文卡片的内外边距 SHALL 收紧到不挤压正文字宽的程度。

#### Scenario: 窄屏选择器不挤压正文
- **WHEN** 视口宽度小于 1024px 进入文档页
- **THEN** 文档选择器单独占据一行且宽度等于容器内容宽度
- **AND** 正文在其下方使用容器全部可用宽度

#### Scenario: 宽屏三栏不受影响
- **WHEN** 视口宽度达到 1024px 及以上
- **THEN** 左栏文档列表与正文同排显示，选择器不渲染
- **AND** 视口达到 1280px 且有标题目录时右栏 TOC 一并显示

#### Scenario: 极窄视口正文字宽优先
- **WHEN** 视口宽度小于 640px
- **THEN** 正文卡片内边距收紧，正文文本宽度优先于装饰性留白
