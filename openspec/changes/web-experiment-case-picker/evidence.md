### 2026-11-07：案例选择器溢出修复

- **现象**：报告「案例对比」切到「交替」后，`review-01…review-20` 的单选按钮排成一行，超出 960px 正文列，页面横向溢出。
- **原因**：`n-radio-group` 内部按钮不换行，作为一个 flex 子项被撑宽；`.cases-toolbar` 的 `flex-wrap` 只作用于整组，不作用于组内按钮。
- **修复**：改为 `n-select`（`casePickerOptions`，宽 176px），保留「并排 / 交替」按钮组。
- **构建**：`npx vite build` 通过。
- **待确认**：用户目视确认（任务 1.3）。
