## ADDED Requirements

### Requirement: 运动隐空间表征（零训练主链 + 可选自监督增强）

系统 SHALL 以**预训练视频编码器零训练特征**为隐空间主表示：跟随视角视频 → 窗口特征（VideoMAEv2 / DINOv2，经选型实验定主用）→ 聚类/探针；关键点序列仅作辅助信号（在场率/运动强度/簇命名参考）。仅当零训练特征基线不达标时，才启动自监督学习版（**已拆为独立 change `identity-action-tokenizer`**：FLOAT 式参考输入 + 正交运动基、连续潜空间无量化、重建 + 感知 + 对抗损失）；训练全程不使用动作标签；训练/验证切分 MUST 按源视频分组。

#### Scenario: 主表示选型实验

- **WHEN** 在验收跟随视频 + 抽样白天段上分别运行 VideoMAEv2 与 DINOv2 窗口特征提取
- **THEN** 输出对比报告（UMAP 簇可命名性 / 相邻窗口特征时序连续性），选型结论与判定标准一并记录，编码器接口为可插拔实现

#### Scenario: 聚类与人工标签一致性

- **WHEN** 对有 5 类人工标注的白天段数据计算聚类一致性
- **THEN** 报告 NMI/ARI 数值，并输出每个簇的标签构成占比

#### Scenario: 线性探针对照实验

- **WHEN** 线性探针训练完成
- **THEN** 报告 top1，对照组 = 同一编码器在原始整帧视频上的特征；参考组 = VideoMAEv2 全量微调基线
