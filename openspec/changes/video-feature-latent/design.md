# Design: video-feature-latent

> 继承总管 D3（修订版隐空间架构）、D8（主表示选型实验设计）。本文件不重复，只记执行参数。

## Decisions

### L1: 窗口特征口径

- VideoMAEv2：16 帧窗口 stride 8 → CLS token（768d），用 mmaction2 已有权重
- DINOv2：逐帧 patch 均值池化 → 窗口内时序均值（768d/1024d）
- 两候选在同一批跟随视频上跑：UMAP 可视化 + 相邻窗口余弦距离（时序连续性）+ 人工看簇代表帧可命名性
- 判定：可命名簇比例为主，打平取 VideoMAEv2（时序原生）

### L2: 探针对照

主对照 = 同一编码器在**原始整帧**（未跟随处理）视频上的特征——检验跟随预处理增益；参考 = VideoMAEv2 全量微调基线（现有评测体系）。

### L3: 自训版触发条件

零训练基线「人工可命名率 <60%」或探针低于原始帧对照时，启动总管 D3 的可选学习版（输入 = 视频特征序列 48×768，VQ K=512）。
