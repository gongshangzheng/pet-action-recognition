## 3. 猫数稳定性判定

- [ ] 3.1 按稳定性判据实现区间级多宠物标记：统计基准为锚点（`frame % sample_stride == 0`），覆盖率为锚点中 `pet_count ≥ 2` 的占比，并同时记录最长连续锚点数；阈值由现有 3,117 个区间的分布选定（参考：覆盖≥0.5 且连续≥3 时命中 565 个）。判据：阈值、依据与该阈值下判为多猫的区间数写入 evidence。（依赖 2.1）
- [ ] 3.2 输出中间清单：单猫 / 多猫 / 无可靠检测三类互斥，且三类计数之和等于可映射区间总数。判据：清单路径与三类计数写入 evidence。（依赖 3.1）
