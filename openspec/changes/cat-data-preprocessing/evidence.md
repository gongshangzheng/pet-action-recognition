# 证据记录

### 2026-11-07：activity 性质与切片规模实测

- **activity 是什么（经验刻画，非标注指南原文）**：原始 2,352 个区间，时长中位 7.2 秒（p10 2.7、p90 18.9）；2,573 段带标注视频里有 1,199 段（47%）**整段只标 activity**；只有 11% 的 activity 区间与其他标签在时间上重叠；按帧计，activity 独占帧 305,480，与其他标签共占 37,156（独占约 89%）。结论：activity 是“猫在活动/移动”的粗粒度状态，不是具体动作。
- **筛选后剩余（标注层面，未含检测相关筛选）**：可映射区间 3,893 → 排除短于 1 秒 33 条 → **3,860 条候选**；其中 607 条需要左右外延，3,253 条已 ≥4 秒。
- **切片规模（4 秒窗、50% 步长的理论上限）**：23,578 个片段。分类别：activity 8,559（36%）、prolonged_stationary 4,960（21%）、eating 4,706（20%）、scratching 2,421（10%）、drinking 2,056（9%）、grooming 653（3%）、toileting 177（1%）、gnawing 43、fall 2、seizure 1。
- **检测相关筛选尚未运行**：多猫与无检出两项需要先补检测 429 段视频。参考已有检测覆盖子集的实测比例——区间级多猫 605/3,111（19.4%）、旧流程无可靠检测 945/2,710（34.9%）——预计筛完剩余区间在 2,100–2,200 量级，此为推算，不作结论。
- **activity 下采样影响**：activity 占切片上限的 36%。若只保留其 30% 片段，总量从 23,578 降到约 17,587。具体比例与规则待用户定。
