### 2026-11-07：VideoMAEv2 官方采样口径核对

- **本项目现状**：`clip_len=16, frame_interval=4, num_clips=1`，训练与测试都只取区间正中的 61 帧（约 4.07 秒）；不是“原速播放”，而是把真实 4 秒压缩成 16 帧，区间其余部分丢弃。
- **官方 VideoMAEv2（ViT-B，K710→K400）配置**：训练同为 `16×4` 单 clip；**测试 `num_clips=5`、`average_clips='prob'`**，即在整段上取 5 个 `16×4` 窗口并平均概率。骨干的 `num_frames` 固定为 16，不存在可变长度输入；所谓“处理任意长度”是靠多窗口采样加平均。
- **对本轮的影响**：我们只取中段一个窗口，指标与官方协议的差异来自两处——窗口数量与覆盖范围。报告需要写明这一点，不能与官方口径的公开数字直接比较。
- **后续可选方案（未采纳）**：训练时按区间切多个 4 秒窗口、每窗口作独立样本；评测时 `num_clips=5` 覆盖整段并平均。已记入 design 的 Open Questions。

### 2026-11-07：切片机制定稿（分层随机，一次性产出）

- **用户提问**：为什么要滑窗，而不是在区间内随机取起点。**滑窗是 agent 提的机制，不是用户定的**，已撤回。
- **定稿方案**：片段 60 帧；位置用分层随机——区间按可容纳片段数切成 k 段（k = min(4, 可容纳数)），每段内随机取一个起点，种子固定并写入清单；片段在预处理阶段一次性产出，训练与评测读同一份清单，不做每 epoch 重采样。
- **否决理由**：滑窗在 123 秒区间上产 60 个高度相似片段；纯随机可能扎堆；每 epoch 重采样使样本不可复述。
- **未变的决定**：每区间最多 4 个片段、短于 1 秒排除、1–4 秒左右外延。

### 2026-11-07：多宠物（而非多猫）统计口径修正

- **术语**：全流程统一为“多宠物”（`cat_count + dog_count ≥ 2`），不再说“多猫”。狗在这批语料里普遍存在：2,144 段已检测视频中 1,616 段（75%）出现过狗；区间级仅 44 条是纯狗区间，1,541 条是“1 猫 + 1 狗”。
- **两次错误结论作废**：此前报“连续性判据下多宠物区间为 0”，两次都是测量错误。第一次用全部帧做“连续”，非锚点帧的计数为 0，连续性永远断；第二次只取 `source == "detected"` 的帧，而多宠物锚点恰好被写成 `source == "invalid"`（因严格规则判为不可用），正好被过滤掉。
- **修正后的判据基准**：锚点 = `frame % sample_stride == 0` 的检测帧。按此统计 3,117 个区间（`pet_count ≥ 2`）：
  - 覆盖率 ≥0.1：1,293；≥0.3：854；≥0.5：585
  - 连续锚点 ≥2：1,299；≥3：1,044；≥5：789
  - 覆盖率 ≥0.5 且连续 ≥3：**565**
- **含义**：约 565 个区间在多宠物判据下是“稳定多宠物”，占已检测区间的 18%，不是 0。这个数才是“剔除多宠物会损失多少”的起点。
- **未解决**：多宠物区间目前无法做个体级裁剪。`scripts/pet_detect_track.py` 只取最高置信度框并插值，两只动物同时在时会静默跳到另一只身上（`tracker-selection` change 的设计已指出此风险，但该 change 未验证）。SORT 未实现。且标注没有身份字段，即使有跟踪也无法确定标注指哪只。

### 2026-11-07：多宠物计数改为先规整检测（v8）

- **用户判断**：20 条抽查里“得有一半只有一只猫”。据此不再把人工逐条审阅当作主要手段，先量化检测本身的重复与退化。
- **抽查量化（20 条）**：5 条两框 IoU = 1.00、面积比 1.00（同一只猫重复报）；多条第二框面积比在 0.04–0.23（小物件）或 2.0–9.7（整片场景）。
- **新计数规则**：按面积取主框 → 丢弃 IoU ≥ 0.8 的重复框 → 丢弃面积比 < 0.15 或 > 3 的退化框 → 剩余 ≥ 2 才计为多宠物。
- **效果（v7 → v8）**：多宠物 967 → **482**；进入切片 2,867 → **3,339**；片段 6,285 → **7,554**；eating 750 → 1,211；drinking 365 → 594；activity 3,425 → 3,784；prolonged_stationary 1,159 → 1,309；外延失败 106 → 143；重叠压制 11 → 22。
- **结论上界**：这仍是检测驱动的判定，规则只消除“重复框与退化框”这两类已知错误；真实的多宠物漏检（两只猫只报一只）不在本规则覆盖范围内。
- **对 2.3 的影响**：逐条人工审阅不再是主要判据，改为在规整后仍判多宠物的区间中抽 5 条确认；已完成的 20 张图保留为过程记录。
