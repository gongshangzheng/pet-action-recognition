**最好段 `event_20260618_233630`（cons=1.0）**

> **2026-11-07 更正（用户复核）**：上一条“彻底丢失”的判断**错了**。用户确认：那只活动的猫在 frames 0–25 之后就**真的出了画面**，不是跟丢。因此 id0 只覆盖 6 个锚点是**正确行为**，该段轨迹数 2 = 个体数 2 也是真实正确，不是数量巧合。由此推翻两条推论：① 该段不构成“漏检后无法重生”的证据（本 change 至今**没有**这类证据）；② “碎片指标对轨迹彻底消失不敏感”仍是指标属性，但此处无实例，不得用作本轮的失败依据。末帧框从 435px 膨胀到 1005px 仍记录在案（猫正离开画面时框变松），但不再归因于跟踪错误。

### 2026-11-07：2.5 阈值对照与结论（判据：结论与逐条阈值对照写入 evidence）

事先阈值（design 4.2，未在看到结果后调整）：交换 ≤2 次/视频、碎片 ≤2 段/个体、3 段抽样的轨迹数与人工数出的个体数完全一致。

| 阈值 | 实测 | 判定 |
|---|---|---|
| 交换 ≤2 次/视频 | 代理信号 0；人工核对未发现两只真实动物之间互换 id | **字面达标**，但身份连续性另有缺陷（见下） |
| 碎片 ≤2 段/个体 | 按聚类指标最大 4；人工核对口径：中位段唯一真猫被拆成 cat id0 + dog id10000 = 2 段（1 个碎片）；最好段移动猫 1 段但仅 6 锚点后永久丢失（指标不计）；最差段真猫 0 轨迹 | **指标超标且指标失灵**（对"轨迹消失后未再检出"不敏感） |
| 3 段轨迹数与人工个体数一致 | 1/3 段一致（最好段，且为数量巧合） | **不达标** |

**结论：不达标**（第三条阈值失败，碎片指标同时超标）。根因方向按贡献排序：

1. **检测侧误检与漏检是主因**，不是关联算法。狗粮包装被当活狗（最差段）、静止杂物被当猫（中位段）都在 tracker 上游，任何关联器都无从纠正——tracker 只能在这两个错误上"忠实跟踪"。
2. **物种分实例策略把物种抖动放大成身份断裂**（中位段 id0 → id10000）。当前实现没有物种稳定性约束：单锚点的物种误判即可在另一物种流里另起一条轨迹。
3. **观测密度不足**：最好段活动的猫 6 锚点后消失，中位段穿越狭窄通道时断档，与 stride=5（3 Hz）下漏检即整段空洞一致。

**未达标的处置**：按 design 4.4 不接入裁剪流程，不降级为最高置信度框；区间结论清单（3.1）不产出。下一步按 design 4.3 用 stride=2 复测（3.2），但需先就"物种抖动"与"误检"两条根因的用户裁决，否则加密锚点只会让误检轨迹更连续。

方法（design 4.10「先裁后分」）：框外扩 15% 裁出，只把裁剪图送模型，box prompt 用框在裁剪图内的坐标；填充率 = (mask ∩ 框) / 框面积；精修框 = mask 外接框映射回原帧。脚本同时输出**原框裁剪 / 精修框裁剪并排对比图**，否则无法判断精修是否变好。

**更正说明**：首版（v1 探针）我把「狗粮包装误检」的用例框取成了 `id3 [1290,543,1552,767]`，那实际是**趴在狗粮袋上的真猫**；真正的误检是袋面印刷的金毛（`id1` f0 180×212、`id4` f80 189×211）。下表是换用正确框后重跑（v2 探针）的结果。

| 用例 | 原框 | SAM2 精修框 | bbox IoU | MobileSAM 精修框 | 说明 |
|---|---|---|---|---|---|
| 印刷金毛 id1 f0（**真误检**） | 180×212 | **178×210** | 0.969 | 172×210 | 几乎不变，mask 分数 0.977 |
| 印刷金毛 id4 f80（**真误检**） | 189×211 | 175×208 | 0.898 | 172×208 | 略收 |

1. **框细化收益很小**：原框与精修框的 bbox IoU 普遍 **0.88–0.97**，尺寸差 1–3%（真猫 262×224 → 259×223）。这说明 GroundingDINO 的框本来就和 SAM 认定的边界接近；只有明显松的框（重复框那类，0.877）才收得动。首版「SAM 会系统性收紧所有框」的判断不成立，已撤回。

### 2026-11-07：5.1 本 change 最终结论

**结论：当前数据条件下不适用于训练裁剪（不接入）。** status=partial、verdict=inconclusive。

**已确认为真的事实（有证据）：**
1. 关联层缺陷可修且已修：物种抖动导致的身份断裂由「单流 + 物种作元数据」消除（中位段假狗轨迹不再生成、猫轨迹 36→40 锚点）；嵌套重复框由 IoS 去重消除（中位段 id2 消失、交换代理信号 16→0）。锚点一致性中位 0.8182→**1.0000**。
2. **观测密度不是瓶颈**：stride=2（成本 2.5×，267 秒）碎片 3→**4**，一段上凭空多出两个估计个体。
3. **关联算法不是瓶颈**：OC-SORT 与关断全部 OC 机制的 SORT 基线**逐帧等价**（10 段 0 帧差异）。
4. **ReID 无实证需求**：两个原始动机一个被单流解决、一个被用户复核推翻（猫是真离场）；重启条件已写死在 3.8。
5. **绑定在本 change 的失败不可解**：碎片/个体最大仍为 3 > 阈值 2；剩余误检（袋面印刷金毛）与框不贴合都属于检测侧，跟踪层无信号可用——四信号判别力为零，且真猫置信 0.331 低于三条误检的 0.502/0.536/0.616。

**明确移交的两条：**
- 误检抑制 → `presence-gate-model`（框级活体判定 + 非活物负样本，其 tasks 第 7 节）。
- 掩码级观测（身体面积占比、轮廓特征）→ 观测指标线；框面积高估 1.5–2.7 倍，该指标只能用掩码。
- 检测器路线（GroundingDINO 标注 → 训练 YOLO）→ 总管 `pet-motion-latent-pipeline` design 同名小节。

**未做且不得宣称：**未产出区间级轨迹结论（3.1 不触发）；未接入任何裁剪或训练侧切换；框细化未接入。
