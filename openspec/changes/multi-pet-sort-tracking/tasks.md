## 1. 实现跟踪器

- [x] 1.1 读取既有检测缓存，把每个锚点的猫狗候选整理成逐锚点的帧序列（含置信度、物种、帧号）。判据：任取 3 段视频，输出的锚点数与 metadata 中 `frame % sample_stride == 0` 的帧数一致。（可与 1.2 并行）
- [x] 1.2 接入 `petlib/tracking` 的 OC-SORT 适配器（use_byte=True），按物种拆分实例（猫流/狗流各一个）并合并 track id，生命周期参数按锚点数标定并随产物记录。判据：合成用例中两条平行移动的轨迹保持各自 id，两条交叉轨迹不互换 id。（依赖 1.1）
- [x] 1.3 输出逐锚点的 track id、框、物种与轨迹状态，写入独立目录。判据：同输入同参数重跑两次输出一致（哈希相同）。（依赖 1.1、1.2）

## 2. 实现后的真实样本评估

- [x] 2.1 选取 10 段多宠物视频作为评估集：从既有检测缓存中“覆盖 ≥0.5 且连续 ≥3 锚点”的 565 个区间中按视频随机取 10 段，记录选择规则与随机种子。判据：清单含视频名、区间帧范围、选择种子。（依赖 1.3）
- [x] 2.2 在评估集上运行 OC-SORT 跟踪器，统计身份交换次数、每只的轨迹碎片数、轨迹总数。判据：`metrics.json` 含三个指标与逐视频明细。（依赖 2.1）
- [x] 2.3 原版 SORT 在同一评估集同批运行，指标对照写入 evidence。判据：对照表含两种算法的三指标与差异说明。（依赖 2.1；可与 2.2 并行）
- [x] 2.4 人工核对 3 段：生成轨迹叠加帧（每个 track 一种颜色）与个体数量标注，由用户判断是否与画面一致。判据：3 段的核对结论写入 evidence。（依赖 2.2）
- [x] 2.5 按事先阈值给出结论：交换 ≤2 次/视频、碎片 ≤2 段/个体、3 段抽样轨迹数与人工数一致。判据：结论与逐条阈值的对照写入 evidence；不达标时写明根因方向，并参照 2.3 的 SORT 对照区分算法与观测密度问题。（依赖 2.4）

## 3. 单流关联与按需 ReID

ReID 很贵，按 design 4.8/4.9 分档推进：先用零成本的单流修掉物种抖动，只在纯运动确实无解时启用外观。

- [x] 3.1 【记录】2.5 判定不达标，原 3.1（达标才做的区间三分类）本轮不执行；不触发原因写入 evidence。判据：evidence 有一节写明“区间三分类未触发”及依据。（依赖 2.5）
- [x] 3.2 实现单流关联臂（零成本）：去掉物种分实例，所有检测进同一 tracker 流，物种改为轨迹元数据（多数投票 + 一致性比例）。判据：合成用例中同一目标在物种标签抖动下保持同一 track id；产物记录 `species` 与一致性比例。（依赖 3.1；不需要新依赖、不解码视频）
- [x] 3.3 在同一 10 段评估集跑单流臂，与 1.2 的硬分实例基线对照，重点看中位段物种抖动是否消失。判据：指标对照表与逐视频碎片数写入 evidence。（依赖 3.2；可与 3.4 的准备工作并行）
- [x] 3.4 人工核对中位段与最好段：确认物种抖动断 ID 是否消失、活动猫是否仍只覆盖 6 锚点。判据：两段核对结论写入 evidence。（依赖 3.3）
- [x] 3.5 输入侧嵌套重复去重（design 4.11）：读检测缓存时，类内去重除 IoU 外增加 `IoS = 交集/较小框面积 ≥ 0.8` 判重（保留置信度高者）。判据：中位段 frames 185/215 的紧框+松框只剩一个；评估集真实个体数不因误删而下降。（依赖 3.4）
- [x] 3.6 用去重后的输入重跑单流臂，与 3.3 对照，看幻影轨迹是否消失。判据：指标对照表 + 中位段 id2 是否不再生成，写入 evidence。（依赖 3.5）
- [x] 3.7 轨迹级只记录原始信号（design 4.12）：产物为每条轨迹记录 `mean_conf`、`median_area_ratio`（占画幅比）、`nearest_track_gap_anchors` 与 `suspect_reasons`，**不输出“是否误检”结论、不删除轨迹**。判据：产物含四个信号字段且无 verdict 字段；8 条人工标注轨迹的信号值与判别力结论写入 evidence。（依赖 3.6）
- [x] 3.8 判断是否仍需 ReID：若 3.6/3.7 显示“长间隙重生”或“同色交叉”仍未解决，实现按需 ReID 臂（只在轨迹重生与匹配歧义两类事件上算外观，osnet 权重 17MB），并记录调用次数；若已达标则记录“ReID 未启用”并跳过。判据：启用或跳过的依据写入 evidence。（依赖 3.7；启用前需用户确认下载权重）
- [x] 3.9 若至 3.8 仍不达标：用 `stride=2` 加密锚点在同一 10 段上复测，判断差距来自关联还是观测密度。判据：两种锚点密度的指标对照写入 evidence。（依赖 3.7）
