## 1. 实现跟踪器

- [ ] 1.1 读取既有检测缓存，把每个锚点的猫狗候选整理成逐锚点的帧序列（含置信度、物种、帧号）。判据：任取 3 段视频，输出的锚点数与 metadata 中 `frame % sample_stride == 0` 的帧数一致。（可与 1.2 并行）
- [ ] 1.2 接入 `petlib/tracking` 的 OC-SORT 适配器（use_byte=True），按物种拆分实例（猫流/狗流各一个）并合并 track id，生命周期参数按锚点数标定并随产物记录。判据：合成用例中两条平行移动的轨迹保持各自 id，两条交叉轨迹不互换 id。（依赖 1.1）
- [ ] 1.3 输出逐锚点的 track id、框、物种与轨迹状态，写入独立目录。判据：同输入同参数重跑两次输出一致（哈希相同）。（依赖 1.1、1.2）

## 2. 实现后的真实样本评估

- [ ] 2.1 选取 10 段多宠物视频作为评估集：从既有检测缓存中“覆盖 ≥0.5 且连续 ≥3 锚点”的 565 个区间中按视频随机取 10 段，记录选择规则与随机种子。判据：清单含视频名、区间帧范围、选择种子。（依赖 1.3）
- [ ] 2.2 在评估集上运行 OC-SORT 跟踪器，统计身份交换次数、每只的轨迹碎片数、轨迹总数。判据：`metrics.json` 含三个指标与逐视频明细。（依赖 2.1）
- [ ] 2.3 原版 SORT 在同一评估集同批运行，指标对照写入 evidence。判据：对照表含两种算法的三指标与差异说明。（依赖 2.1；可与 2.2 并行）
- [ ] 2.4 人工核对 3 段：生成轨迹叠加帧（每个 track 一种颜色）与个体数量标注，由用户判断是否与画面一致。判据：3 段的核对结论写入 evidence。（依赖 2.2）
- [ ] 2.5 按事先阈值给出结论：交换 ≤2 次/视频、碎片 ≤2 段/个体、3 段抽样轨迹数与人工数一致。判据：结论与逐条阈值的对照写入 evidence；不达标时写明根因方向，并参照 2.3 的 SORT 对照区分算法与观测密度问题。（依赖 2.4）

## 3. 接入或停止

- [ ] 3.1 若达标：为每个标注区间输出轨迹结论（单一目标 / 多目标可枚举 / 身份不可靠），并输出失效清单。判据：三分类计数之和等于评估区间的总数，失效项都带原因。（依赖 2.5）
- [ ] 3.2 若不达标：用 `stride=2` 加密锚点在同一 10 段上复测一次，判断差距来自算法还是观测密度。判据：两种锚点密度的指标对照写入 evidence。（依赖 2.5）
