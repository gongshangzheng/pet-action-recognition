# Proposal: spot-check-cli

> 子 change，总管：`pet-motion-latent-pipeline`。前置：`video-feature-latent` 完成（隐空间表征可用）。

## Why

**生产形态 = 实时监控 + 非实时抽查双模式（2026-09-16 用户修订）**：
- **抽查模式**：指定「某摄像头某时间段」→ 拉录像 → 预处理 → 隐码 → 深度动作报告（分钟级）
- **实时模式**（新增）：接入 live 视频流 → 在线检测/特征/最近簇分配 → SSE 推送状态（秒级），复用 live 模块现成流式基础设施
两种模式共享同一份行为簇字典（离线发现、在线分配）——**同一模型内核、两种外层契约，不是两套模型**。

**术语精确化（2026-09-17）**："实时"不是指 RTF < 1（吞吐），而是指**端到端延迟 + 因果性**：
- **模型内核**吃 16 帧窗口 → 实时模式用**滚动窗口**（`[t−15, t]`）推理，与训练**完全一致**，**零重训代价**，延迟 = 窗长（≈0.5 s @30fps）
- **差异只在时序后处理**：抽查用全局非因果平滑（段边界更准）；实时用因果在线平滑（边界有固有延迟）
- 真低延迟内核（延迟 < 窗长）需因果注意力 + 流式重训 → **v2 条件启动**，不在本 change 范围

## What Changes

- `scripts/spot_check_actions.py`：抽查 CLI（动作报告 JSON/MD：标签/起止秒/track_id/登记身份/置信度/疑似新动作/猫在场率/**空间状态段**）
- **实时监控服务**：live 流接入 → 在线检测（YOLO11 快速版，伪标注微调）→ 最近簇分配 → SSE 状态推送（复用 server/routers/live.py 基础设施）
- `scripts/register_cats.py`：猫个体档案（登记照 → embedding（模型待实测）→ 向量库检索），未登记个体标「未知猫 #N」
- 端到端联调（3 个真实时段，含 1 个无猫时段）+ L2 边界误差抽查（±1.5s）
