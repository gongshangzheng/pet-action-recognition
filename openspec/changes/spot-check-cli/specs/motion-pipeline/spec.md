## ADDED Requirements

### Requirement: 抽查式推理管线

生产推理 SHALL 为非实时抽查形态：输入「摄像头 + 时间段」→ 管线执行检测→居中→持续跟踪→隐码→输出动作报告（动作标签 + 起止时间 + 置信度 + 未识别簇提示 + **空间状态段**）。无猫时段 SHALL 输出空报告并给出猫在场率统计。全程不要求实时，处理延迟可接受分钟级。

#### Scenario: 抽查一段无猫时段

- **WHEN** 指定时间段内猫不在画面
- **THEN** 输出空动作报告 + 猫在场率 0%

#### Scenario: 抽查输出动作报告

- **WHEN** 指定时间段内有猫活动
- **THEN** 报告含逐段动作标签、起止时间（秒）、track_id（哪只猫）、置信度、空间状态段；出现低相似度簇时提示「疑似新动作」

#### Scenario: L2 时序切分

- **WHEN** 动作码序列发生持续突变
- **THEN** 报告在该时间点输出动作切换边界，边界误差在滑窗粒度（±1.5s）内
