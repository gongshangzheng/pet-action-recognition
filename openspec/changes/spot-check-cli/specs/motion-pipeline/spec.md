## ADDED Requirements

### Requirement: 抽查式推理管线

生产推理 SHALL 提供**双模式**（2026-09-16 用户修订），且两模式 MUST 共享同一份行为簇字典（离线发现 / 在线分配）：
- **非实时抽查**：输入「摄像头 + 时间段」→ 管线执行检测→居中→持续跟踪→隐码→输出动作报告（动作标签 + 起止时间 + 置信度 + 未识别簇提示 + **空间状态段**）。无猫时段 SHALL 输出空报告并给出猫在场率统计；处理延迟可接受分钟级
- **实时监控**：复用 live 模块流式设施，按秒级粒度推送当前状态（SSE）

#### Scenario: 抽查一段无猫时段

- **WHEN** 指定时间段内猫不在画面
- **THEN** 输出空动作报告 + 猫在场率 0%

#### Scenario: 抽查输出动作报告

- **WHEN** 指定时间段内有猫活动
- **THEN** 报告含逐段动作标签、起止时间（秒）、track_id（哪只猫）、置信度、空间状态段；出现低相似度簇时提示「疑似新动作」

#### Scenario: 实时监控状态推送

- **WHEN** 实时模式开启且猫出现在画面并跳上床
- **THEN** 系统在秒级内通过 SSE 推送状态 `cat on bed`，动作簇分配随帧流持续输出

#### Scenario: L2 时序切分

- **WHEN** 动作码序列发生持续突变
- **THEN** 报告在该时间点输出动作切换边界，边界误差在滑窗粒度（±1.5s）内
