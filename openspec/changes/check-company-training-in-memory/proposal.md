# 公司环境小规模训练检查

用户要求改测训练：动作识别使用 `/home/work/pet_analysis_wyy` 的 dataset 和 annotation，标签路径暂不修改；其他模块有训练实现时可以检查，无需训练的跳过。该请求授权范围受限的实际反向传播与内存参数更新，不启动正式长训练。

范围：TSN 与 X3D-S 使用少量实际公司视频的行为标注区间；YOLO11n 检测/分割、MobileNetV3-Small、LR-ASPP、U2-NetP PyTorch、小型因果 TCN 使用合成监督做训练接口检查。rembg/ORT 仅推理接口本身不训练；PELT、GrabCut、跟踪规则和 RKNN 不做训练。

沿用此前不保存数据要求：输入、中间结果、loss、更新后权重均只留内存，终端显示状态。原视频、标注、权重、配置和实验索引保持不变。不安装/下载，不执行新的独立前向或完整业务链路测试。脚本和 OpenSpec 先提交再同步服务器执行。

验收：数据加载/预处理、有限 loss、反向传播、有限非零梯度及实际参数更新；每条神经网络路径最多三个 optimizer step。报告区分真实/合成输入、底层训练接口/正式包装器、未匹配路径和失败项。小规模 loss 不作为准确率或收敛结论。
