## 2. 布局改造

- [ ] 2.1 改为侧栏加正文：侧栏放筛选条件与报告列表，正文放选中报告；复用 `DocPage` 的侧栏 class 与折叠交互。判据：列表不再被 `n-card-header` 包裹，侧栏可折叠，选中项有 active 态。（依赖 1.1、1.2）
- [ ] 2.2 调整正文宽度：去掉整篇的 76ch 限制，段落限宽、表格/代码块/案例图占满正文区，表格容器加横向滚动。判据：1440px 与 1024px 下宽表格不溢出正文、段落行宽在 70–80ch 之间。（依赖 2.1）
- [ ] 2.3 页面级标题与元信息：报告标题作为唯一 `h1`，状态/结论标签与 run、date 放在标题下方；侧栏标题降为 `h2`。判据：DOM 中仅一个 `h1`，标题层级不跳级。（依赖 2.1）
- [ ] 2.4 章节导航：由报告实际章节生成导航，点击跳转并按滚动位置高亮。判据：缺少某章节时该项不出现；点击「结论与下一步」能定位到该节。（依赖 2.2、2.3）
- [ ] 2.5 响应式：≥900px 侧栏常驻，<900px 侧栏转抽屉、正文单列。判据：768px 下正文无横向溢出，抽屉有明确开关按钮。（依赖 2.1）
