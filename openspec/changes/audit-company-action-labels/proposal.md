# 公司行为标签只读分布审计

用户要求浏览当前公司标注，重点核实追逐和打闹是否过少，并允许这些类别
在本轮训练中暂缓。此前“先不要清洗”仍有效，本次不实施类别排除或标签转换。

本 change 记录只读调研范围：读取已生成的视频路径版 CSV/JSON，统计
各标签区间、独立视频及覆盖帧数，比较两种导出并检查时间重叠。
不运行模型、不解码视频、不下载原始公司标注或视频、不写远程数据文件。

新增可复用标准库脚本，先提交，再从本机经现有 SSH 会话送入远程 Python
内存执行；服务器只输出汇总，不落脚本或报告文件。汇总结论留在本地文档与设计中。
该范围属于 AGENTS.md 允许的纯只读调研；后续清洗、类别词表或训练需另行计划审核。

验收：说明标签计数口径及重复/重叠，不把区间数当独立样本数，
不把缺失的标签宣称为标注工具中未定义，区分零观测与未核实类名。
明确追逐、打闹的观测数量及本轮建议；不承诺现有数据达到验收指标。
