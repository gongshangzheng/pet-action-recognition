## ADDED Requirements

### Requirement: 猫本体抠像（背景移除）

系统 SHALL 提供猫本体抠像能力：给定一段视频与猫的检测信息，输出**仅保留猫本体像素、其余区域置黑**的视频。输出 MUST 与原视频**帧数、帧率、分辨率一致**（逐帧对齐），且 MUST NOT 覆盖或修改原视频（抠像产物另存）。抠像 MUST 消除背景运动信息（相机随猫移动导致的场景变化），确保下游 tokenizer 的逐帧动作表征不被背景污染。

#### Scenario: 正常视频抠像

- **WHEN** 对一段猫全程可见的 followcam 视频执行抠像
- **THEN** 输出同帧数、同帧率、同分辨率的视频，猫本体像素保留，其余区域为黑

#### Scenario: 不覆盖原视频

- **WHEN** 抠像完成
- **THEN** 原视频文件保持不变，抠像产物写入独立路径

#### Scenario: 掩码质量异常兜底

- **WHEN** 某段视频出现掩码面积突变、时序漂移（帧间闪烁）或检测丢失
- **THEN** 系统 MUST 检出并标记该段（不静默输出脏数据），并按既定回退策略处理（回退最近有效掩码 / 时序平滑 / 标记为需人工复核）

### Requirement: 抠像模型轻量化与许可合规

系统 SHALL 采用**轻量级、实时可用级**的背景移除模型执行抠像（单帧推理在实时量级，不引入重型视频分割依赖），以支撑全语料批处理的高吞吐。所用模型**权重许可 MUST 允许本项目使用**（禁用非商用许可权重）。所用模型名称、权重许可、单帧耗时 MUST 留档于 design。

#### Scenario: 模型选型留档

- **WHEN** 确定抠像模型
- **THEN** design 中记录模型名、权重许可（SPDX 或等价）、单帧耗时，并确认非非商用许可

#### Scenario: 全语料批处理吞吐

- **WHEN** 对全量语料（34 + 2234 + 717 段）执行抠像批处理
- **THEN** 在单卡 GPU 上完成时间 MUST 在小时级以内

### Requirement: 掩码与检测框一致性校验

抠像所用的背景移除模型为**显著物体分割**类，存在"选错对象"风险（背景有更显眼物体时）。系统 SHALL 用现有猫检测框对掩码做一致性校验：掩码质心 MUST 落在检测框内，框内掩码面积占比 MUST 高于阈值；不满足时 MUST 标记告警，不得静默输出。

#### Scenario: 分割到错误对象

- **WHEN** 某帧掩码质心落在猫检测框外（如分割到大碗/靠垫）
- **THEN** 系统标记该帧/该段为告警并输出告警原因，不静默写入脏产物

### Requirement: 抠像批处理与产物清单

系统 SHALL 支持对全量语料批量抠像，并产出**可核对的清单**（每段视频的处理状态：成功 / 失败 / 告警）。批处理 MUST 可续跑（跳过已完成项），且 MUST 在 GPU 任务前检查设备占用。

#### Scenario: 批量处理产出清单

- **WHEN** 对 followcam / mammal_v0 / cats v1 全量语料执行批处理
- **THEN** 产出清单文件，逐条记录每段视频的处理状态与失败原因（若有）

#### Scenario: 中断后续跑

- **WHEN** 批处理在中途中断后重新执行
- **THEN** 系统跳过已完成项，只处理未完成项
