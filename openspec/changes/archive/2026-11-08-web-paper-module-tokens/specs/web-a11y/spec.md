## ADDED Requirements

### Requirement: 论文模块与全站主题同源

论文列表与论文详情的文本、卡片面、边框、悬停态 SHALL 使用 `--color-*` 令牌，MUST NOT 使用独立的硬编码调色板，使深色模式下不再出现浅色岛屿。

#### Scenario: 深色模式下的论文卡片
- **WHEN** 在深色模式打开论文列表
- **THEN** 卡片底色、标题、作者、日期、摘要均取深色令牌值，文本对比度 ≥4.5:1

#### Scenario: 浅色模式下的次要信息
- **WHEN** 浅色模式渲染英文标题、日期、缩略图占位、作者行
- **THEN** 这些次要文字在其实际底色上对比度 ≥4.5:1

#### Scenario: 钉住态标记
- **WHEN** 论文被置顶
- **THEN** 用主色浅底与置顶按钮表达，不叠加超过 1px 的彩色左边框
