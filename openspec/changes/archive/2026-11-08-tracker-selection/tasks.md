# Tasks: tracker-selection

编号为执行顺序，跨章节严格串行；每项均未完成。原始教师候选生成独立于此队列，不等待跟踪选型或去重。旧九项原文和映射见 [task-map](task-map.md)。

## 1. 规则与案例

- [ ] 1.1 讨论重复框与关联候选规则；判据：记录位置随时间的连续性、两只真动物保护、歧义及框取舍的候选与未决项，不预先确定阈值。
- [ ] 1.2 核对少量代表性真实连续案例；判据：记录可用样本及人工观察和无法判断项，涵盖可获得的重复框、两动物靠近或交叉及遮挡等案例，不重跑教师检测。
- [ ] 1.3 用户确定身份 GT 与指标口径；判据：样本、身份及可见性、匹配规则、指标定义和不可判定项的处理记录在 evidence。
- [ ] 1.4 用户选择候选、规则参数及预算；判据：选择、适用范围与资源授权记录在 evidence；真实案例不足以支持规则时先补充案例，不进入实现。

## 2. 跟踪与重复处理

- [ ] 2.1 制作获批样本的身份 GT；判据：逐视频身份及不确定区域可追溯，人工核对结果留证。
- [ ] 2.2 接入获选跟踪候选；判据：候选可读取相同检测缓存及必要源帧，配置与来源可追溯，不静默回退；OC-SORT 仅为已有基线。
- [ ] 2.3 实现共享因果重复框处理；判据：先处理明显同帧重复，再结合历史位置和已有轨迹复核，保留 raw 与处理理由、歧义及两只真动物，不默认取包围 union。
- [ ] 2.4 按获批决定处理离线后视复核；判据：采用时产出独立标注未来信息和关联依据的结果；不采用时记录用户明确决定及理由，不将未实现说成已实现。
- [ ] 2.5 对接 `pet-pipeline` 的逐帧框与裁剪能力；判据：对接结果可追溯轨迹来源，区分观测与估计并显式标示缺失和不确定，不重复实现数据导出。

## 3. 评估与裁定

- [ ] 3.1 验证离线数据准备路径；判据：在固定已有教师候选和获批 GT 上记录重复处理、轨迹及裁剪的核对结果，后视结果单独标识。
- [ ] 3.2 验证在线因果路径；判据：用固定已有 YOLO 输出及对应源帧记录人工核对和延迟；若缺少输入则停止并报告，不擅自运行检测。
- [ ] 3.3 比较获选候选；判据：同输入、规则及划分下记录获批身份和裁剪指标、失败案例及实际硬件资源，不用平滑度代替身份真值。
- [ ] 3.4 发布综合报告；判据：汇总 GT、离线和在线证据、参数限制及未解决风险，不声称重复轨迹或裁剪零错误。
- [ ] 3.5 用户裁定跟踪选择及接入范围；判据：记录选择或暂不选择、依据及后续条件，不自动设置默认跟踪器或归档。
