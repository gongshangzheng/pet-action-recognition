## MODIFIED Requirements

### Requirement: 区间猫数判定与多猫排除

区间 SHALL 依据帧级猫数被判定为单猫、多猫或无检测三类之一，三类互斥且都记入报告。含两只及以上猫的帧出现过的区间 MUST 记录为多猫；多猫区间不再整段排除，而是交给按轨迹裁剪的流程（见 change `multi-pet-track-cropping`）。

按轨迹处理时，**判定单位 MUST 是 `(区间, 轨迹)`**：每条轨迹各自判断覆盖、缺口与物种稳定性，一条轨迹被淘汰 MUST NOT 影响同区间其他轨迹。同一区间有多条轨迹通过时，产出的片段 MUST 记录轨迹 id 并标记身份不确定。

#### Scenario: 区间内出现两只猫

- **WHEN** 区间内至少一帧检测到两只及以上猫
- **THEN** 该区间标记为多猫，交接给按轨迹裁剪流程
- **AND** 逐轨迹给出通过或淘汰的明细，淘汰项写明原因

#### Scenario: 静物被判成第二只宠物

- **WHEN** 区间内第二条检测框对应的是毛绒玩具、摆件或海报
- **THEN** 该框不计入宠物数，区间不因它被判为多宠物
- **AND** 判据至少包含置信度下限与跨锚点位移两项

#### Scenario: 多轨迹中只有一条可用

- **WHEN** 同一区间内有两条轨迹，其中一条因遮挡或缺口被淘汰
- **THEN** 另一条轨迹仍按自身覆盖与连续性独立产出片段
- **AND** 片段记录轨迹 id，该区间标记身份不确定

#### Scenario: 猫数判定的可靠性被抽查

- **WHEN** 多猫判定首次产出
- **THEN** 人工抽查若干单猫与多猫区间，核对判定是否与画面一致
- **AND** 抽查结果与不一致原因写入证据
