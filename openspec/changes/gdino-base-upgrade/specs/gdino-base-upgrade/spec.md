## Purpose

规定教师模型从 GroundingDINO-tiny 升级到 base 的能力：升级前必须通过小批对照的量化闸门（判据事先写定），全量重跑必须冻结口径且产物隔离，新教师产出的数据集与学生必须与旧一代可追溯对照。全量重跑不得在闸门未过时启动。

## ADDED Requirements

### Requirement: 升级闸门——小批对照先行

换用更大教师 SHALL 先在已人工核对的样本段上做 base vs tiny 逐锚点对照，对照判据 MUST 在跑之前写定并写入 change；任一判据未达标时不得启动全量重跑。

#### Scenario: 印刷动物误检对照

- **WHEN** 对照运行在含狗粮袋印刷金毛的段上
- **THEN** 报告分别给出 base 与 tiny 在印刷物区域内的检出框数、置信度与持续锚点数
- **AND** 报告明确判定 base 是否减少了把印刷动物判为活物的锚点

#### Scenario: 判据未达标

- **WHEN** 事先写定的任一闸门判据未满足
- **THEN** 记录"不值得全量重跑"及具体数字，change 在此收口
- **AND** 不启动全量检测，也不产生新数据集

### Requirement: 全量重跑的口径冻结与产物隔离

全量重跑 SHALL 与现有 tiny 缓存同口径（全视频、stride=5、box_threshold=0.3、cat/dog 两类），产物写入独立目录并记录教师权重指纹；不得覆盖或修改既有 tiny 缓存。

#### Scenario: 口径一致可对照

- **WHEN** 全量重跑完成
- **THEN** 任取一段视频，base 缓存与 tiny 缓存的锚点帧号序列完全一致
- **AND** 两份缓存的教师指纹可区分且各自完整

#### Scenario: 区间外帧保留

- **WHEN** 某锚点位于标注区间之外且无检出
- **THEN** 该锚点仍保留在缓存中（空候选），作为负样本来源
- **AND** 不得只导出区间内的锚点

### Requirement: 新教师到新学生的可追溯链

新数据集 SHALL 记录 base 教师指纹；教师指纹变化 MUST 触发数据集重建而非增量合并；新学生的评测 SHALL 与旧一代（tiny 教师、其学生）三方对照报告，且明确标注各方的教师来源。

#### Scenario: 指纹触发重建

- **WHEN** 导出脚本检测到教师指纹与数据集记录不一致
- **THEN** 拒绝复用旧数据集并要求全新导出

#### Scenario: 三方对照

- **WHEN** 新学生训练与评测完成
- **THEN** 报告并列给出 YOLO(base)、YOLO(tiny) 与 tiny 本人的一致率与速度
- **AND** 每一方标注其教师指纹与训练 epoch 数
