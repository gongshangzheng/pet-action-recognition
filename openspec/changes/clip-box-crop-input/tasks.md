## 1. 裁剪框数据

- [ ] 1.1 在片段清单生成阶段写入 `crop_box`：取片段内锚点目标框并集、外扩 10%、转方形；多宠物片段用轨迹框。判据：抽样 10 条片段打印 `crop_box` 与来源锚点数，范围都在视频尺寸内。（依赖 `multi-pet-track-cropping` 1.1 的视频清单；可与 1.2 并行）
- [ ] 1.2 统计框覆盖率与面积占比：有框片段数、回退整帧数、`crop_box` 面积占画幅比的中位数与 p90。判据：四个数字写入 evidence。（可与 1.1 并行）
- [ ] 1.3 产出新索引版本 `datasets/cat_clip_v9`（含 `crop_box`），不覆盖 v8。判据：索引文件行数与 v8 一致、抽样 20 条能读到 `crop_box`。（依赖 1.1）

## 2. 读取时裁剪

- [ ] 2.1 实现 `IntervalBoxCrop` transform：按 `crop_box` 裁方形并缩放，缺框回退整帧。判据：20 条片段的首/中/末帧导出对照图，人工确认主体在框内。（依赖 1.3）
- [ ] 2.2 小批吞吐测试：50 条片段跑一遍 dataloader，记录每迭代耗时与峰值内存，判断是否需要改为离线导出。判据：耗时与内存写入 evidence。（依赖 2.1）

## 3. 对照训练与结论

- [ ] 3.1 用裁剪输入跑 20 轮（同一 seed、同一片段清单），保存配置、环境、日志、checkpoint 与权重哈希。判据：状态为完成、best 检查点按 macro-F1 选出、四类产物齐备。（依赖 2.2）
- [ ] 3.2 与整帧臂对照：top-1、macro-F1、逐类 recall 与 support，注明 A 臂仅 4 轮的部分结果。判据：对照表写入 evidence 与报告。（依赖 3.1）
- [ ] 3.3 抽检 20 条裁剪片段，记录裁错比例与失败类型（框过大、框偏移、框缺失）。判据：抽检结论写入 evidence。（依赖 2.1）
- [ ] 3.4 结论与下一步：裁剪是否带来可辨识提升、是否需要第三臂（逐帧跟框）、是否需要重跑完整 A 臂。判据：结论写入 evidence 与报告。（依赖 3.2、3.3）
