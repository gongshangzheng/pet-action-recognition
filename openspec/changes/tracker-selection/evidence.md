# 证据

## 历史协调记录

`pet-pipeline` 已采用单流 OC-SORT，2,335 视频历史跟踪产物不证明多宠身份质量；旧 0.1–0.3、1.1–1.6 共九项未勾，人工 GT、算法矩阵和质量指标未完成，非当前主线前置。建议用户确认按 superseded 保留未勾状态关闭并归档，关联质量仍作为后续可选评估；目前未归档。

以上关闭建议及将 OC-SORT 当作已选方案的表述已由以下用户决定纠正；本 change 保持 active，OC-SORT 仅为已运行基线。

## 用户决定与依赖边界

用户明确跟踪器今后可替换：GroundingDINO-base 离线教师按已定第 0 帧起 stride 5 生成猫狗候选框、类别与置信度；跟踪选型消费检测结果，不是原始检测或去重的前置。原始候选独立版本保存；时序去重、关联规则及跟踪参数仍待裁定。候选及缓存限制见 [design](design.md)。

本轮未更改九项任务、编号、状态或并行关系；既有教师小批核对、权重来源、用户选择和资源授权要求不变。现有 spec 仅要求检测源固定后对比跟踪器，没有要求先选跟踪器再检测，故未修改。`pet-system-integration` 已将 OC-SORT 标为非最终选型，未修改。本轮仅修订规划，未启动 GroundingDINO-base 检测、训练或远程运行，也不授权全量运行。
