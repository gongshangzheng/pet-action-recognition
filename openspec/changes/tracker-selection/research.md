# 跟踪候选研究

本节汇总 2026-11-08 只读调研，供用户选择对照，不是模型选型或实验授权。建议先比较已有 OC-SORT 与无 ReID Hybrid-SORT，再将 Deep OC-SORT 的外观分支作为独立增量对照；没有证据证明它们在本项目猫狗场景中胜出。动物和红外证据有限，当前没有本域身份 GT 对照结果。

## 候选与限制

- **OC-SORT（CVPR 2023）**：现有运动基线。观测中心更新可研究遮挡后的运动误差，但虚拟轨迹不是身份真值。现有产物不证明多宠关联已达标。
- **Hybrid-SORT（AAAI 2024，无 ReID）**：值得优先对照运动基线，使用置信度、框高度等弱线索；猫狗姿态、红外或类别分数变化可能误导关联。本域收益未知。
- **Deep OC-SORT（2023）**：外观增量对照，区别于 2017 年 DeepSORT；现有行人 ReID 权重不能假定适用于猫狗、小目标或红外。外观对照需要源帧；motion-only 是明确对照或消融，不是静默回退。
- **ByteTrack**：可比较低分候选二次关联，但无法找回教师阈值已丢弃的框。是否保存更多低分框须用户决定，不自行下调阈值。
- **BoostTrack++**：低分增强的次级候选，可能受输入截断和误检影响；优先级较低不等于判定其较差。

离线全视频 tracklet 链接是独立架构维度，可利用未来观测，但可能错连，需人工身份 GT 核验；不等同于插值。中间帧 CSRT 和 SAM 2/3 视频分割仅为备选，不是主线或身份保证；SAM 3 的权重访问、版本及适用条款未在本轮复核。分割结果不是个体身份真值。

## 对照口径建议

训练数据准备和在线 YOLO 推理都需要重复框处理；位置随时间的连续性是主要线索，但不保证身份正确。先做明显的同帧处理，再结合已有轨迹复核，不确定时保留歧义；共用的因果处理仅看当前及过去，离线未来帧复核另报。阈值、窗口和框融合规则尚待用户确认，不强制引入外观。

按视频划分并人工审阅样本，固定检测候选和同帧去重；对比 IDSW、误合并、误拆和碎片，以及 crop 宠物包含率、空裁与重复 crop。按昼夜、小目标、交叉和遮挡分层，在实际硬件报告延迟与资源。身份 GT 的匹配阈值、样本数量、可见性口径和预算由用户确认；框位移代理值不能冒充 GT 误差。严格因果在线与有未来帧的离线结果分开报告，不以更平滑等同身份更准，也不跨硬件搬用 FPS。

15 fps、stride 5 的检测观测频率为 3 Hz。跟踪器生命周期与历史间隔参数应核实每次 update 的含义，再按秒尺度决定；固定机位不强制 CMC。具体代码缺口及原始候选、处理候选的边界见 [design.md](design.md)。

## 来源与证据深度

本次整理依据四份只读报告：运动与关联 `task-1.md`、外观 `task-2.md`、中间帧及离线方案 `task-3.md`、本库代码 `context.md`；报告位置见 [evidence.md](evidence.md)。报告对官方仓库 README 和部分关键源码做了核查，论文主要为摘要或部分章节，动物证据深度因来源而异；本次未联网复核，移动分支和权重许可须在后续使用前固定版本并另查。

- [OC-SORT 论文](https://arxiv.org/abs/2203.14360) 与 [官方实现](https://github.com/noahcao/OC_SORT)。
- [Hybrid-SORT 论文](https://arxiv.org/abs/2308.00783) 与 [官方实现](https://github.com/ymzis69/HybridSORT)。
- [Deep OC-SORT 论文](https://arxiv.org/abs/2302.11813) 与 [官方实现](https://github.com/GerardMaggiolino/Deep-OC-SORT)。
- [ByteTrack 论文](https://arxiv.org/abs/2110.06864)；[BoostTrack++ 论文](https://arxiv.org/abs/2408.13003)。
- [AnimalTrack](https://arxiv.org/abs/2205.00158) 说明动物外观相似和运动变化带来困难；其结果不保证外观特征在本域有增益，也不是室内 3 Hz 猫狗公平对照。
- [SAM 2 官方仓库](https://github.com/facebookresearch/sam2) 为视频 mask 传播参考，不证明身份连续。
