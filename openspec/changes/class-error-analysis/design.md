# Design: 逐类错误分析

## 目标

回答「逐类差距从哪来」并给出可核查的证据，不训练、不调参、不做阈值实验。产出必须是可复现的分析报告，而不是一次性观察。

## 分析对象

`clipv9-b` 的测试产物 `results/cat_clip_v9/videomaev2_b/test_metrics.json`：1,130 条逐样本预测（真实标签、预测标签、10 类分数），以及同一批渲染片段 `results/cat_clip_v9/assets/clips/test/`（60 帧、256×256、15fps）。

## 四类证据

1. **逐类指标**：TP/FP/FN、precision、recall、F1，recall 与 precision 都给 95% Wilson 区间。小 support 类只看点估计会误导：`toileting` 14/18 与 `drinking` 41/60 的区间宽度完全不同。
2. **错误流向**：10×10 混淆矩阵 + 每类错误去向，以及「错误流向 activity」的汇总量与「永远判 activity」基线（51.59%）。
3. **画面描述量**（不参与训练、与模型输出无关，因此可作诊断量）：每片段取 10 帧（步长 6 ≈0.4 秒）算平均亮度、HSV 饱和度（<30 作红外代理）、帧差均值（整体运动量）、16×16 分块 95 分位帧差（局部动作幅度）。
4. **人眼复核**：按「每个混淆对取置信度最高的候选、同一源视频只留一条」选样，再由作者显式挑选进正文；每条 case 记录输入、选择理由与 sha256。

## 判定方式

不设验收阈值，判据是「数值、错误流向、描述量、人眼复核四者是否指向同一解释」。四者不一致的写成未确认；单例只算存在性证明，不推广为比例。

## 案例取样规则（防止样本偏差）

- 判错侧：取置信度最高的若干条（模型最「确信地错」的样本），再补不同去向的样本，避免全是同一去向。
- 判对侧：按来源轮转、同一来源只出一条，优先覆盖不同亮度；否则会被单一来源（同一家庭的狗扒门）占满，读者会误以为那是全类的典型画面。
- 误报侧：取「真实标签不是该类、模型判成该类」的片段，与判错/判对并列。
- 对照图每段只取第 30 帧，视频保留完整 4 秒原片段，不做增强或挑选片段改动。

## 非目标

- 不提出并验证修复方案（裁剪策略、补标、重训、阈值拒识都不在本 change 内）。
- 不把片段级数字换算成区间级或端到端结论。
- 不裁定标注是否正确：只指出同一视觉模式下存在两种标签，需要人工复核。

## 已知边界

- 片段不是独立样本：1,130 条片段来自 484 个标注区间，区间级置信区间比片段级宽。
- 区间内行为漂移用「窗口间运动量极差」作代理，是下限估计，未逐区间人眼确认，也不能排除跟踪框漂移造成的假漂移。
- `gnawing`（4 条）、`fall`/`seizure`（0 条）不可评估。
- `species` 字段经抽查不可靠，按设备前缀而不是物种做拆解。
