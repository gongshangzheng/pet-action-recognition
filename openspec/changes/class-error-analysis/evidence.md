# Evidence: class-error-analysis

### 2026-11-12：十类片段分类的逐类错误分析（cliperr-20261112a）

- **skill 闸门**：已加载 experiment skill（本 change 的产物是实验报告与分析脚本）。
- **类型**：感知质量（不训练、不调参、不做阈值实验）。
- **baseline**：`results/cat_clip_v9/videomaev2_b/test_metrics.json`（pet）：测试 1,130 条片段，top-1 85.75%、macro-F1 56.23%、balanced accuracy 54.62%。
- **可辨识性**：画面描述量（运动量、局部运动、亮度、饱和度）由片段本身计算、不参与训练，可作诊断量；留一来源敏感性给出逐类指标对单一来源的依赖幅度（去掉 `charw1g`：top-1 85.75 → 86.70，`scratching` recall 56.4 → 46.4）。
- **对照**：无干预臂（本 change 只做归因）；「永远判 activity」基线 51.59% 作为对照参照。
- **结果表**（测试集，片段级）：

- **关键结论**
  1. 模型主要依据画面运动量分流：判成各类的片段运动量中位数为 `prolonged_stationary` 5.7 → `activity` 19.2 / `scratching` 19.3；类内三分位错误率随运动量单调变化（`activity` 19.6 → 4.1%，`prolonged_stationary` 3.6 → 22.9%），唯 `scratching` 三档齐平（46 / 38 / 46%）。
  2. 错误流向：161 个错误里 62 个（38.5%）流向 `activity`，但 `activity` 只被预测 582 次（support 583），不存在系统性多报；更准确的说法是两个吸引子（高运动量 `activity`、低运动量 `prolonged_stationary`）。
  3. `scratching` 的 precision 与 recall 低是两件事：漏判 17 条中 14 条流向 `activity`（置信度中位 0.963，86% ≥0.8），是「猫自挠」动作小、夜间/遮挡；误报 12 条中 9 条来自单一来源 `charw1g`，与判对组是同一构型（直立扒竖直面），差别只在源标注。
  4. 训练集已含同一构型的两种标签：训练集 `scratching` 236 条中 159 条（67%）来自 `charw1g`；同来源 65 条 `activity` 中，区间 138–197 一条的末段同样出现「狗直立扒玻璃门」。
  5. 标注单位与取样叠加：区间 `event_20260802_053844:1-235` 的 15.67 秒里只有前约 4 秒是活动，切出的三个测试窗口（49–108 / 93–152 / 120–179）运动量 6.88 / 2.70 / 1.13，全部落在站定段并全部判成 `prolonged_stationary`。
  6. 片段非独立样本：1,130 条片段来自 484 个区间；313 个多窗口区间里，窗口间运动量极差中位 1.83×，21 个（6.7%）同时跨活动档（≥15）与静止档（≤5）。
- **这个指标不测量什么**：片段级条件准确率不测量可用率与区间聚合；混淆矩阵不说明成因；运动量等描述量只说明「错误与这些量共变」，不是因果。
- **样本量**：测试 1,130 片段 / 484 区间；人眼复核 15 条片段 + 20 条 scratching 对照（7 漏判 / 7 判对 / 6 误报）+ 5 条训练片段 + 1 个完整标注区间（15.67 秒）。
- **失败边界**：`gnawing`（4 条全错，全为红外极暗画面）、`fall`/`seizure`（0 条）不可评估；`charw1g` 的 activity/scratching 标注口径未裁定；`species` 字段抽查不可靠（3 条 dog 标签中 1 条画面是猫），未做物种结论；区间漂移用极差作代理，是下限估计。
- **结论与其上界**：能说明错误集中在哪几条边界、各自与什么量共变、哪些成因属于输入表示/标注口径而非模型容量；不能说明任何修复方案有效，也不构成端到端或区间级成绩。
