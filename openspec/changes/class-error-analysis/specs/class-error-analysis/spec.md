## Purpose

规定逐类错误分析的证据口径与报告要求，使「为什么某几类准确率明显偏低」这类问题有一致的回答方式：既给全局口径，也给逐类准确率、区间数与来源依赖，并用可核查的素材支撑解释。

## ADDED Requirements

### Requirement: 同时报告整体口径与逐类口径

分析 MUST 在同一处说明四个口径各自的含义与归属：条件 top-1 准确率（达标判定所用）、端到端准确率（可用率 × 条件准确率）、逐类准确率（等于该类召回率，其补数为该类漏检率）、宏观指标（macro-F1 / balanced accuracy）。MUST NOT 把逐类召回画在整体目标的验收线上冒充逐类验收标准。

#### Scenario: 读者只看得到逐类柱状图

- **WHEN** 报告给出逐类准确率图表
- **THEN** 同页必须说明整体目标值、当前整体值，以及逐类数值没有独立验收线
- **AND** 明确逐类数值的补数就是该类漏检率

### Requirement: 逐类指标给出区间与区间数

逐类 precision / recall SHALL 给出 95% Wilson 区间；每类 SHALL 同时给出片段数与独立标注区间数。当某类片段数与区间数差距明显时，MUST 指出片段不是独立样本。

#### Scenario: 小样本类别

- **WHEN** 某类测试片段少于 20 条
- **THEN** 报告必须给出置信区间宽度，并声明该宽度是否允许下结论

### Requirement: 错误归因需四类证据互证

归因结论 SHALL 由四类证据共同支持：逐类指标、错误流向、与模型无关的画面描述量（运动/亮度/红外代理/局部动作）、以及人眼复核的素材。四者不一致时 MUST 标记为未确认，不得以单例推广为比例。

#### Scenario: 只用指标下结论

- **WHEN** 仅凭混淆矩阵推断成因
- **THEN** 该推断不得写入结论，只能写入待验证问题

### Requirement: 案例取材规则显式、可核查

报告案例 MUST 由作者显式选择并在 manifest 登记 `input`、`selection_reason` 与 `sha256`；选中素材 MUST 以行内引用嵌入正文，结构化案例区只补未内联项。判对侧取样 MUST 按来源轮转，避免被单一来源占满。

#### Scenario: 案例全部堆在文末

- **WHEN** 报告有案例素材
- **THEN** 正文对应段落必须就地引用该素材，行内引用数等于 manifest 案例数

### Requirement: 区分模型错误与标注/取样问题

当错判可归因于标注粒度、区间切分或窗口取样时，报告 SHALL 明确这类错误不能记在模型账上，并给出可复核的素材（区间整段、逐帧运动量、相邻窗口表现）。

#### Scenario: 同一区间产出多条错判片段

- **WHEN** 多条测试片段来自同一标注区间且全部判错
- **THEN** 报告必须检查该区间的时间跨度与窗口落点，并说明错判是模型问题还是取样问题
