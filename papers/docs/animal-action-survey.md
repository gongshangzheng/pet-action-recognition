## §0 问题定义：什么是宠物动作识别（PAR）

### 0.1 一句话定义

> **给定一段以家养伴侣动物（猫、狗等）为主体的视频，识别其中发生的动作类别及其时间范围，服务于家庭场景下的行为理解、健康监测与实时交互。**

### 0.2 形式化与任务层级

- **输入**：视频 `V`（通常来自固定家庭摄像头；含 1 只或多只宠物；可能同时含人、物体、人宠/宠宠交互）
- **输出**：按任务层级分三级——

| 层级 | 任务 | 输入→输出 | 代表方法范式 | 本项目对应 |
|---|---|---|---|---|
| **L1 分级识别** | clip-level classification | 视频片段 → 动作标签集合 | mmaction2 分类器（VideoMAE/SlowFast 系） | 训练模块 + run_test top1/top5 |
| **L2 时序检测** | temporal action detection | 长视频 → [(动作, 起止时间, 执行者)] | OpenTAD 类离线检测；live 在线滑窗 | 评测模块时序扩展（规划）；Live SSE 逐段输出 |
| **L3 开放世界发现** | open-world behavior discovery | 无类别表 → 自动发现并聚类动作模式 | MoSeq/Keypoint-MoSeq/B-SOiD 无监督范式 | 标注类别表设计的前置步骤 |

- **执行者属性**：与人类动作识别不同，PAR 天然要求 **identity-aware**——多宠家庭必须回答"哪只猫在做什么"（动作识别 × Re-ID 耦合）。

### 0.3 与相邻任务的边界

| 相邻领域 | 区别 |
|---|---|
| 通用动物行为识别（Animal Kingdom / MammalNet） | 它们面向 850 物种/野生动物，**粗粒度、跨物种泛化**；PAR 面向**固定小物种集合（猫/狗）的细粒度日常动作**，追求单物种深度 |
| 实验室动物行为分析（MARS / MoSeq / B-SOiD） | 实验室 = 受控背景 + 模式动物 + 离线；PAR = **家庭非受控场景**（杂物、光照变化、家具遮挡）+ 实时 |
| 野生动物监测（KABR / MammAlps） | 野外无人机/相机陷阱、保护导向；PAR 家庭生活导向，含**人宠交互**动作 |
| 人类动作识别（Kinetics 系） | 类别空间不重叠（猫的踩奶/炸毛在人类动作空间无对应类）；但**预训练知识可迁移**（方法论上最重要的联系，见 §5） |

### 0.4 四个本质难点（PAR 作为独立研究问题的依据）

1. **物种特有类别空间**：动作表必须在物种内定义（"踩奶"只有猫有）；个体差异大 → 长尾 + 开放集是常态
2. **细粒度 + 时序跨度悬殊**：甩尾（0.5s）到睡觉（数小时）跨 4 个数量级，单一采样策略必然顾此失彼
3. **多主体耦合**：多宠同框 + 人宠交互 → "谁在做什么、和谁互动"（识别 × 追踪 × 交互检测三合一）
4. **部署约束内生**：家庭摄像头 = 边缘算力 + 隐私本地化 + 7×24 长时流——是问题定义的一部分，不是工程附注

### 0.5 类别判定标准（标注与评测的操作性定义）

> 一个片段值得标注为独立动作类，当且仅当：① 有明确起止；② 对健康/行为理解有语义价值（"转身"不算，"反复舔左前爪"算——可能是皮肤病信号）；③ 在猫/狗中可复现、可枚举。

类别表的产生方式：**L3 先行**（Keypoint-MoSeq/B-SOiD 无监督聚类发现自然动作簇）→ 按上述三条人工归并命名（L1/L2）。类别表是发现出来的，不是拍脑袋列出来的。

## §2 动物动作识别发展脉络（三个时代）

### 2.1 行为学工具时代（2013–2018）

| 工作 | 出处 | 贡献 |
|---|---|---|
| JAABA | Nature Methods 2013 | 轨迹特征 + 交互式标注，行为分类前身 |
| MotionMapper | J R Soc Interface 2014 | 运动嵌入低维空间，无监督行为聚类开端 |
| MoSeq | Neuron 2015 | 自回归 HMM 发现亚秒级"行为音节"（syllable）——**无监督动作分解思想的源头** |

时代特征：依赖受控实验室环境；"行为可无监督发现"的思想延续至今（L3 任务的雏形）。

### 2.2 深度学习双路线时代（2018–2022）

**姿态驱动路线**：DeepLabCut（Nat Neurosci 2018 📌，几十帧标注迁移）→ SLEAP（Nat Methods 2022，多动物）→ MARS / B-SOiD（Nat Commun 2021）/ A-SOiD（Nat Methods 2024，主动学习）。特征：关键点序列 → 轻量分类器；数据效率极高、遮挡鲁棒、可解释。

**视频像素路线**：DECADE（`1803.10827`，CVPR 2018，最早的狗行为数据集）→ DeepEthogram（eLife 2021）/ LabGym（Cell Rep Methods 2023）。特征：端到端、不需要关键点表；数据需求大、背景敏感。

**同期人类动作识别主干**（为 PAR 提供骨干与范式）：Two-Stream（`1406.2199` 📌）→ I3D/Kinetics（`1705.07750` 📌）→ SlowFast（`1812.03982` 📌）→ TimeSformer/ViViT/MViTv2/Video Swin → VideoMAE（`2203.12602` 📌）系自监督。

### 2.3 基准与基础模型时代（2022–2026）

- **Animal Kingdom**（`2204.08129` 📌，CVPR 2022）：850 物种、动作/姿态/定位三任务——动物版 Kinetics
- **MammalNet**（`2306.00576` 📌，ICCV 2023）：1.8 万视频 173 类哺乳动物行为
- **SuperAnimal**（`2203.07436` ⭐，Nat Commun 2024）：跨物种姿态基础模型，**四足零样本**
- **APT-36K**（`2206.05683` ⭐）/ **AP-10K**（`2108.12617` ⭐）：姿态+追踪基准，人体预训练迁移证据
- **AmadeusGPT**（`2307.04858`，NeurIPS 2023）：自然语言 → 行为分析代码

## §3 宠物/家养动物子领域现状

### 3.1 公开基准盘点

| 数据集 | 年份 | 物种/场景 | 粒度 | 与 PAR 的距离 |
|---|---|---|---|---|
| DECADE（`1803.10827`） | 2018 | 狗（第三人称视频） | 9 类行为 | 最近，但规模小、非监控视角 |
| Animal Kingdom（`2204.08129`） | 2022 | 850 物种 | 粗粒度 | 远（跨物种广度） |
| MammalNet（`2306.00576`） | 2023 | 173 类哺乳动物 | 中粒度 | 中 |
| CVB（`2305.16555`） | 2023 | 牛（养殖场固定机位） | 6 类 | 中（固定机位+监控视角同构） |
| MammAlps（`2503.18223`） | 2025 | 野生动物（多视角监控） | 行为监测 | 中（场景同构、物种不同） |
| 3D Dog Pose（`2406.14412`） | 2024 | 犬 3D 姿态 | 姿态 | 姿态子任务 |
| BigMaQ（`2602.19874`） | 2026 | 猕猴运动/动画 | 图像↔3D 姿态 | 远 |

### 3.2 自有数据现状：cats 数据集（专门节）

#### 四层组织

| 层 | 位置 | 内容 |
|---|---|---|
| 原始层 | `datasets/cats/*.zip`（本地） | 79 段摄像头事件片段 `event_*.mp4`，**2880×1620 @15fps**，单段数十秒；**夜间红外 45 + 白天 34**（按文件名时间戳） |
| 标注层 | `annotation_{崔,蒋}.zip` | Label Studio 时间线标注（`ranges[{start,end}] + timelinelabels`）——**本质是 L2 时序标注**，切段后才压扁成 L1 |
| 训练层 | `~/mnt/cats/quadruped_cats_v1`（pet NAS） | `slice_cats_clips.py` 切段：4s clip / stride 2s（50% 重叠）→ **717 clips**（train 528 / val 88 / test 101） |
| 外部参照 | `pet_action_mammal_v0` | 第三方哺乳动物集：2234 段、7 类、train 1801/val 216/test 217（未经人工视觉复核） |

#### 标注统计（2026-09-07 解析，去重后）

- **标签全集就是 5 个**（`common/` 命名空间）：activity（50 段）、prolonged_stationary（24）、grooming（11）、eating（9）、drinking（2）——按时间段计；`activity` 是伞类，占总数一半
- **69/79 有标注**（10 段未标注）
- **每段视频的动作数**：51 段单标签、**18 段含 2 个动作**（如 activity+eating、activity+prolonged_stationary，首尾衔接或分段）——**多动作视频真实存在**，但最多 2 类/段，无同时并发标注
- **长尾**：drinking 仅 2 段（切 clip 后仅 9 个），对应用核心问题一

#### 数据质量问题（选型/训练前必读）

1. **时间单位不一致（严重）**：多标签视频的 range 终点普遍远超视频时长（如 115s 视频标到 1859）——疑似不同标注人混用了**秒/帧**两套单位（1859 帧 ÷ 15fps ≈ 124s ≈ 视频末尾，吻合）。切段继承了这些 range，**clip 标签边界可信度存疑，需先做单位审计**
2. **切分泄漏风险**：4s clip 以 2s stride 重叠切段后随机 split——同一源视频的相邻 clip 可能分跨 train/test，指标虚高；**建议按源视频分组切分**
3. **昼夜域偏移无元数据**：45 段夜间红外与白天 RGB 是两个视觉域，且都与 K400 RGB 预训练有域差；clip 元数据应显式记录 `day/night`，否则模型可能在学昼夜而非动作
4. **粒度粗**：activity 是伞类；对照 §0.5 类别判定标准，需 L3 无监督发现（Keypoint-MoSeq/B-SOiD）细化类别表

### 3.3 空白分析

arXiv 检索 **"pet action recognition" 结果为空**；家养猫/狗的细粒度家庭动作（踩奶、踩便、挠沙发、甩尾）**无公开基准**。现有数据集全部是野生动物/实验室动物/畜牧动物。**结论：自建猫狗细粒度数据集本身就是可发表的数据贡献点**，也是本平台的差异化护城河。

## §4 最新方法专讲（2024–2026）

> 每篇按「动机 / 方法 / 对本项目的启示」组织。⭐=已入库 core

### 4.1 动物姿态与追踪

- **DiffPose-Animal**（`2508.08783`）：语言条件扩散模型做动物姿态——生成式姿态估计范式首次进入动物域。启示：对遮挡下的关键点不确定性建模有潜力，暂列观察。
- **Promptable Animal Pose Tracking Across Species**（`2608.04995`，2026）：SAM 式可提示追踪跨物种化。启示：Live 模块"框选宠物→持续追踪+动作识别"的产品形态有了学术对齐。
- **AP-CAP**（`2504.00394`）：可控图像合成生成高质量动物姿态训练数据。启示：**核心问题一的合成数据路线的最新证据**，但仅覆盖静态姿态。
- **MamKPD**（`2412.01422`）：Mamba 实时 2D 关键点检测。启示：边缘端姿态桥接的低延迟选项。
- **AnimalMotionCLIP**（`2505.00569`）：运动信息嵌入 CLIP 空间。启示：图文对齐范式做零样本动物行为描述的入口。
- **Probabilistic Prompt Distribution Learning**（`2503.16120`）/**不确定性感知多视角**（`2510.09903`）：动物姿态的概率化/数据高效方向。

### 4.2 行为发现与分析

- **Keypoint-MoSeq**（Nature Methods 2024，doi:10.1038/s41592-024-02318-2）⭐：关键点追踪 + 姿态动力学（SLDS）自动切分行为音节，跨实验室泛化强。启示：**L3 任务的首选工具**——先发现自然动作簇再定类别表。
- **A-SOiD**（Nature Methods 2024）：主动学习 + 无监督嵌入，极少专家标注获得高精度分类器。启示：标注成本高的宠物场景的标注效率方案。

### 4.3 基础模型 × 动物行为

- **BehaviorVLM**（`2603.12176`，2026）：免微调 VLM 行为理解。启示：与已集成 Qwen3-VL（Qwen2.5-VL 后继，`2502.13923`）路线互相印证——VLM 做零样本行为描述/问答，分类器做可控 top-k，双轨互补。
- **AmadeusGPT**（`2307.04858`）：LLM 生成行为分析代码。启示：降低姿态流水线使用门槛的交互范式。

### 4.4 动作识别主干最新进展（服务 PAR 的骨干选型）

- **V-JEPA 2**（`2506.09985`）：特征空间预测自监督，理解/预测/规划三能力——MAE 之后的表征学习新范式，观察。
- **VideoMamba**（`2403.06977`）/ **MS-Temba**（`2501.06138`）/ **MambaTAD**（`2511.17929`）：线性复杂度长时序——live 长时流的候选。
- **OpenTAD**（`2502.20361`）：时序动作检测统一框架——**L2 任务的工具箱起点**。
- **AIM**（`2302.03024`）⭐ / **Task-Adapter**（`2408.00249`）⭐：图像基础模型 + Adapter 的高效适配，小数据正解（已接入 registry：`aim-vitb-adapter`）。
- 骨架自监督：MaskSem（`2508.12948`）/ MS-CLR（`2508.14889`）；标签高效：Informative Sample Selection（`2510.25345`）。

## §5 两大核心问题的证据链

### 5.1 核心问题一：动物数据稀缺

| 对策 | 代表证据 | 适用性判断 |
|---|---|---|
| 🥇 自监督域继续预训练 | VideoMAE（`2203.12602` 📌，3.5k 视频即可预训练）/ VideoMAE V2（`2303.16727` ⭐） | **最优单点投入**：live 无标注录像上掩码续训 |
| 🥈 参数高效微调 | AIM（`2302.03024`）⭐ / Task-Adapter（`2408.00249`）⭐ | 同数据下更不易过拟合；已接入（1.38% 可训练参数） |
| 🥉 零样本姿态桥接 | SuperAnimal（`2203.07436`）⭐ | 零标注引入骨架监督信号 |
| few-shot 元学习 | OTAM（`1906.11415`）⭐ / TRX（`2101.06184`）⭐ / HyRSM（`2204.13423`）/ STRM（`2112.05132`）/ MoLo（`2304.00946`）/ 综述（`2407.14744`）⭐ | **不正面硬刚**：增益集中在 1–5 shot；每类 20–50 段直接微调即胜出；长尾兜底保留 |
| 合成数据 | SMAL（`1611.07700`）/ BARC（`2203.15536`）/ AP-CAP（`2504.00394`）/ AnimateZoo（`2404.04946`） | 姿态保真可、动作动态弱；仅辅助增广 |

### 5.2 核心问题二：人类模型 → 动物迁移

| 证据 | 结论 |
|---|---|
| Cross-Domain Adaptation for Animal Pose（`1908.05806`，ICCV 2019） | 人体姿态域 → 动物域无监督适应可行 |
| APT-36K（`2206.05683`）⭐ | 人体预训练迁移**显著优于从头训练** |
| ViTPose++（`2212.04246`）⭐ | 人体姿态基础模型直接扩展到动物 |
| MammalNet（`2306.00576`）📌 | 定量量化 Kinetics → 动物行为迁移增益 |
| Human-Cat 不变表征（`2511.02404`） | 人-猫图像表征不变性系统研究 |
| ZebraPose → 奶牛（`2510.22618`） | 跨物种迁移在畜牧场景落地 |

**主路径结论**：Kinetics 预训练骨干（Video Swin / VideoMAE / UniFormerV2）+ 自有猫狗数据微调。**风险**：动物特有动作（踩奶/甩尾）在人类动作空间无对应类 → 保留开放集/未知类检测。
