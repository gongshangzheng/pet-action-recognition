# 摄像头厂商设备接入

本 skill 帮助定位对接材料并准备联调，不证明任何设备或服务已经实现、上线或验收。以下对接顺序来自 V0.2 材料，是**待实际联调验证的基线**，不是已跑通的操作手册。执行性动作仍须先完成项目 OpenSpec change 并取得明确批准；测试环境和授权设备须由负责人确认。

## 材料入口

材料目录：`docs/摄像头厂商对接材料-外发版-V0.2-20261105/`。材料面向指定合作厂商，按保密约定使用和转交。若目录缺失，向用户或资料负责人索取有权使用的材料；不要假定其他工作区已有副本。

- `README-阅读说明.md`：材料范围、阅读顺序和凭据说明。
- `00-摄像头API清单.md` 与 `00-摄像头API总表.csv`：接口、消息、方向与认证速查。
- `01-摄像头厂商适配文档.md`：身份、HMAC、二维码、直播、控制、对讲和 OTA 的协议基线。
- `03-联调参数与待确认项.md`：阻断项 B01 至 B09、环境参数、产品语义和双方确认。
- `02-对接与验收清单.csv`：逐项验收、责任方和证据；本次查阅的 V0.2 表中结果均为未执行，后续以最新记录为准。
- `05-公开算法测试向量.json`：合成 HMAC、W4 和对讲帧向量，仅用于离线比对。

先查经授权取得的最新材料和确认记录。V0.2 的现有契约、建议值和待确认项属于不同证据等级；实际部署参数和实现需另行核对，不能将草案或接口存在当作已通过真机验收。

## 准备和联调顺序

1. 确认型号、硬件批次、固件、App、服务和网关版本，以及测试环境和设备授权。检查 B01 至 B09 和首版能力矩阵；阻断项没有结论时停止依赖该结论的联调，交责任方确认。
2. 核对产线身份、工厂放行和 HMAC 离线向量，再核对机身码、W4 配网和首次对时。W4 是可逆混淆，不是加密。已消费的 claim 不能作为幂等查询反复重放；响应丢失的恢复方案须先冻结。
3. 区分配网 BOUND 与 READY：complete 成功只到 BOUND，须按材料完成 GB 配置、注册、媒体与心跳就绪检查后才视为 READY。设备 HTTP 心跳、SIP Keepalive、WSS 保活和实际媒体画面分别检查，互不替代。
4. 核对 GB28181 子集、SIP 身份、SDP/RTP 模式和双方冻结的媒体参数。摄像头向媒体服务提供约定的媒体输入，App 与 ZLMediaKit 建立 WebRTC；不要把 App 的 WebRTC 接口当成设备必须实现的接口。
5. 核对设备 WSS 声明的实际能力、请求和会话隔离、云台安全停止和实际到位。`accepted` 只是受理，不是到位；跟踪、隐私、画质和对讲按已冻结能力逐项验收。
6. 按事件上传契约核对完整文件、事件 ID 与 SHA 的重试一致性和归属撤权。`device_pet` 是设备事件类型，不代表具体行为分类已完成。
7. 按冻结的平台、授权任务、签名与回滚方案核对 OTA。材料中的 OTA 是限定平台的应用包更新，不代表任意新硬件或整机升级可直接使用。
8. 按验收表记录步骤、环境、硬件和软件版本、预期与实际结果及脱敏证据。真实首帧、声音、机械到位、隐私生效和回滚须分别验证；不能以接口成功代替。

## 目标边界与安全

材料覆盖设备接入、直播、控制和事件视频上传，不提供完整的行为识别结果或亮度、对比度、活动幅度、身体和面部面积及时长上报契约。这些指标的计算位置、面积分母、有效观测、累计规则和云端判断仍需另行讨论，不能自行补定。

工厂 Bearer、设备 HMAC、设备 Token 和 SIP 凭据各有用途，不能混用。真实密钥、Token、Wi-Fi 密码和 SIP 密码通过受控渠道交付，不写入 skill、仓库、日志或证据。公开合成向量不得用于产品烧录或在线认证。解绑、换绑或过期后的旧 WSS/SIP 终止时机仍须按双方冻结方案验收。

遇到资料缺失、版本或部署状态不明、阻断项未冻结、凭据或设备未授权时，记录缺口并停止相关操作。不能凭旧默认值、成功响应或未验证的能力声明推断系统已就绪。
