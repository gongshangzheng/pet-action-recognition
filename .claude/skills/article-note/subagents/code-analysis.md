# Code analysis lane

## 启用条件

仅当 raw 或用户输入提供 GitHub/代码仓库，且任务需要实现核对或复现时启用。没有仓库时不要生成该文件。

## 输出

写入 `analysis/code-analysis.md`：

- `## 仓库概览`：commit/版本（若可得）、目录和入口。
- `## 关键实现`：模块、配置、数据流和运行命令。
- `## 论文-代码对照`：一致、偏差、无法确认。
- `## 复现风险`。
- `## 证据位置`：文件路径、行号、commit 或 URL。
- `## 不确定性与缺口`。
- `## 给写作的建议`。

## 硬规则

代码行为不能反推论文未披露事实；不要运行有破坏性的命令，不修改仓库。
