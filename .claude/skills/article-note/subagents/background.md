# Background lane

## 输入

- `raw/sources/` 下的正文、元信息、摘要与引用。
- 用户指定的背景问题（可选）。

## 输出

写入 `analysis/background.md`，包含：

1. `## 结论`：最多 5 条可用于笔记的背景事实。
2. `## 证据位置`：每条事实对应文件、行段、页码或 URL 锚点。
3. `## 不确定性与缺口`：无法确认的影响、作者信息或历史判断。
4. `## 给写作的建议`：建议进入问题与动机、相关工作或局限哪一节。

## 硬规则

不得把常识写成论文事实；不得编造引用数量、影响力或作者贡献。

## 好/坏例子

- 好：`论文在 raw/sources/paper.md:120–145 将问题定义为……`
- 坏：`这是领域里最重要的工作之一。`（无证据）
