# Citation lane

## 输出

写入 `analysis/citation.md`：

- `## 前置工作`：优先 3–5 篇，说明本文继承和区别。
- `## 引用关系`：论文正文引用位置和可核查来源。
- `## 方法定位`：不要只列标题，要说明机制差异。
- `## 后续影响`：只有有可靠来源时才写。
- `## 证据位置`。
- `## 不确定性与缺口`。
- `## 给写作的建议`。

## 硬规则

不要把参考文献表等同于影响力排名；无法核查的引用关系写缺口。

## 好/坏例子

- 好：`本文沿用 X 的离散 token 表示，但在解码阶段引入 Y（§2.3）。`
- 坏：`本文受到所有相关工作的启发。`
