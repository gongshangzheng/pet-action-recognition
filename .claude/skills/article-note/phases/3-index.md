# Phase 3：Synthesis index

生成 `.cache/article-note/<slug>/synthesis.md`，通常 200–500 字，超过 1000 字必须重写为指针式索引。

只允许四类内容：

1. 事实位置索引：关键结论对应 raw/analysis 文件和行段、页码或锚点。
2. 跨文件交叉引用：说明 methodology、experiment、terminology 等如何互相支撑。
3. 矛盾标注：论文、代码、不同分析 lane 的数字或叙述冲突。
4. 写作分配建议：每个结论建议进入笔记哪一节，以及需要表格、公式、Mermaid 或图片的位置。

禁止复制或压缩 analysis 正文；synthesis 是导航，不是第二篇总结。缺失代码、训练配置或图片时必须明确标注，并给出替代方案。
