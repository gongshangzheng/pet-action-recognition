# 实验报告模板

报告面向需要理解实验并决定下一步的读者。正文先建立背景，再解释对照和结果；附录供复现与核查使用。占位说明必须根据原始证据填写。

标题按「对象 + 对照或范围」写（≤ 24 个汉字），不把成绩与结论塞进标题；三级小节标题 ≤ 15 个汉字、一条一个。规则见 documentation skill §4.3。

## 背景与目标

[说明研究目标、本次实验的位置及验证的必要性。先解释陌生术语，再使用它们。]

## 当前问题

[说明已有证据和缺失证据，用普通语言提出本次问题，并说明它与整体目标的关系。]

## 实验设计

[解释比较对象、对照、相同条件及判定依据。正文保留理解设计所需的关键数量，精确配置移至附录。]

## 结果与分析

[按实验问题组织观察、少量关键数值和媒体，并就近解释含义与限制。不要按原始字段顺序罗列指标。]

## 结论与下一步

[回答本次问题，区分已验证事实、未解决问题和下一步行动。工具可用、训练完成与模型质量达标分别判断。]

## 附录：配置与完整数据

### 环境与配置

[保留实际记录的版本、设备、精确参数和权重。区分运行现场与事后环境，缺失信息明确标注。]

### 完整指标与定义

[完整指标只展示一次，说明单位、比较对象、样本含义和局限。比较基线与验收阈值分别说明。原始日志单独标注，不让日志标题改变文章层次。]

### 来源与核查

[列出产物位置、哈希、必要命令、选样依据与媒体来源，使正文结论可以追溯。]

生成器叙述字段包括 `background`、`problem`、`design`、`analysis`、`conclusion` 和简短的 `summary`，局限通过 `limitations` 记录。缺少输入时保留明确的草稿提示，不能从目录名推断背景。

> 本模板为默认。历史报告若仍用旧八章（结论摘要 / 实验问题与假设 / … / 产物来源），后端与生成脚本均接受——旧模板标记 legacy 仍完整校验，旧报告不清空。新报告请用本读者导向模板。
